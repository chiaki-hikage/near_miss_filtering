注目する地点の路面に、車輪が通ったときに衝撃や揺れを生むような凹凸が写っているかを判断してください。
凹凸の例: 穴・欠け、マンホールなどの鉄蓋、補修跡 (舗装の打ち替え)、ひび・亀裂、継ぎ目・伸縮装置、段差、減速帯、線路、一帯に荒れた路面、落下物。

## 制約

- 画像に写っているものだけを根拠にすること。写っていないものを推測で補わないこと
- 路面の白線・文字・影・水たまりの跡は、それだけでは凹凸とみなさないこと
- 暗い・ぼやけている・遠すぎるなどで路面が判別できないときは、`visibility` を `poor` か `not_visible` にし、`insufficient_information` を true にすること
- 凹凸が写っていない、または判断できないときは `feature_present` を `no` か `uncertain` にすること。無理に何かを挙げないこと
- 項目の意味
  - `feature_present`: 注目する地点の付近に凹凸が写っているか (`yes` / `no` / `uncertain`)
  - `feature_type`: 凹凸の種類。無ければ `none`
  - `wheel_path`: 凹凸がどこにあるか。`left` 左の車輪の通り道 / `right` 右の車輪の通り道 / `both` 両方にかかる / `between` 左右の車輪の間 / `outside` 車輪の通り道の外 / `unknown` / `none` 凹凸なし
  - `near_target`: 凹凸が注目する地点 (進行方向に前後 2 m 程度まで) にあるか
  - `first_seen_image`: 凹凸が最初に見えた画像の番号。見えなければ 0
  - `description`: 路面の様子と、凹凸があればその見た目と位置を短く書く
  - `evidence_detail`: どの画像のどこを見て判断したか
  - `confidence`: 判断の確からしさ (0〜1)

JSON だけを返してください。
