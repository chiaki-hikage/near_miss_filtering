# 振動起因のロングテール候補探索 PoC (comma2k19 RAV4 Chunk_1)

路面の凹凸・段差による振動のうち、車両挙動に影響した可能性のある区間を探す。
ここで挙げるものはすべて「ロングテール候補」であり、ヒヤリハットとは判定していない。
サスペンション荷重・輪荷重は推定していない。

本体パイプライン (特徴量は CAN のみ) とは独立した PoC で、IMU を主に使う。
本体の検出結果・スリップ検証のコードと出力には影響しない。

| 項目 | 場所 |
|---|---|
| 実行 | `uv run python scripts/vibration/score_longtail.py raw_data/Chunk_1 --clips 5` |
| 設定 (しきい値はすべて暫定) | `configs/vibration.yaml` の `longtail` 節 |
| 共通処理 (IMU 読み込み・帯域通過・普段比) | `scripts/vibration/find_roll_bumps.py` |
| 再利用した既存関数 | `near_miss.features.bicycle_yaw_rate` / `find_lane_changes` / `rolling`、`near_miss.io.comma2k19.load_segment` |
| 出力 | `out/vibration/longtail/`、動画 `out/vibration/videos/lt*.mp4`、図 `out/vibration/plots/lt*.png` |

## 1. 対象データ

- RAV4 Chunk_1 の 188 セグメントのうち、ジャイロが実質 104 Hz の 141 セグメント (14 ドライブ)。
  初期 7 ドライブはジャイロが実質 10 Hz で、ロールの振動を捉えられないため除外した
- 同じドライブの連番セグメントはつないで 1 本 (計 20 本) にした。振動の前後の比較窓が
  60 秒の境界で切れないようにするため
- 使った信号

| 信号 | 出典 | 用途 |
|---|---|---|
| 上下加速度・ロール・ピッチ角速度 | IMU (取付の傾きをドライブごとに補正) | A |
| 4 輪の車輪速 | CAN `wheel_speed` | A の裏付け (左右差・前後輪の時間差) |
| 車速・ハンドル角 | CAN | B、単軌道モデル |
| ヨーレート | CAN 0x024 `YAW_RATE` | B |
| ブレーキ・前後 G | CAN 0x224 `BRAKE_PRESSED`・0x320 `GVC` | 制動中の判定 |
| 位置・進行方向 | `global_pose` (20 Hz) | 地点の照合、軌跡の参考値 |

## 2. 指標

### A: 路面外乱の異常度

上下・ロール・ピッチを帯域通過 (0.7〜20 / 15 Hz) したうえで 0.3 秒の移動 RMS をとり、
同じ車速帯 (5 m/s 刻み) の中央値で割る (= 普段の何倍か)。

    A = sqrt(上下の倍率 × max(ロールの倍率, ピッチの倍率))

A ≥ 3 のピークを振動イベントとする。区間はピークの半分を超えている範囲。
0.5 秒以内に続くイベントは 1 件にまとめる。

### B: 車両挙動の異常度

振動の前 (開始の 5〜0.5 秒前) と後 (終了から 3 秒) を比べる。振動中は IMU も輪速も
揺れて値が汚れるので、挙動は振動が終わった後だけで評価する。

| 成分 | 計算 |
|---|---|
| ヨー | ヨーレート残差 (実測 − 単軌道モデル、0.2〜3 Hz) の RMS の後/前の比 |
| 操舵 | 操舵速度の最大値の後/前の比 (前の値が 2 deg/s 未満なら 2 で割る) |
| 横ずれ | 舵角どおりに進んだ場合の進路からの横ずれ。ヨーレート残差を積分して求める |

振動の無い正常走行から無作為に取った疑似イベント 4,000 件にも同じ計算をかけ、
その分布の上位何 % にあたるかを `-log10` で表す (2.0 = 上位 1%)。B は 3 成分の最大値。

### C: 希少性

全振動イベントのうち、A と B がどちらも自分以上であるものの割合を `-log10` で表す。

### 地点

`global_pose` の位置と進行方向で、半径 25 m・方位差 30° 以内を同じ地点とする。
地点ごとに「通過したドライブ数」と「振動イベントが出たドライブ数」を数える。
同じ地点の繰り返しは独立したケースとして数えない。

## 3. 優先順位

| 優先 | 条件 |
|---|---|
| 1 | 片輪段差の疑い (輪速の揺れの左右差 2 倍以上、ロール/ピッチ比 0.6 以上) かつ、振動後のヨー残差または横ずれが正常走行の上位 1% |
| 2 | 振動後の操舵速度の増え方が正常走行の上位 1% |
| 3 | 制動中 (前後 G ≤ −1.0 m/s² またはブレーキ) または旋回中 (横加速度 ≥ 1.5 m/s²) で、かつ A が全イベントの上位 25% |
| 4 | 振動前 3 秒の、道路の曲率を除いた横の動きが正常走行の上位 1% (回避的な動きの可能性) |
| 5 | A が全イベントの上位 5% |

車線変更の検出 (`find_lane_changes`) と重なったイベントは、B を使う優先 1・2・4 から外す。
複数に当てはまるときは番号の小さいほうを採り、同じ優先の中は A + B + C の和で並べる。

## 4. 結果 (2026-10-09 実行、設定 sha1 `2fbb304670`)

| 段階 | 件数 |
|---|---|
| 振動イベント (A ≥ 3) | 470 |
| 前後の窓が取れて採点できたもの | 422 |
| 優先 1〜5 に当てはまったもの | 61 件 / 36 地点 |
| 上位 20 件 | 15 地点 |

| 優先 | 件数 | 独立地点 |
|---|---|---|
| 1 片輪段差 + 挙動の乱れ | 6 | 6 |
| 2 衝撃後の操舵補正 | 5 | 3 |
| 3 制動・旋回中の振動 | 33 | 18 |
| 4 回避的な軌跡変化 | 2 | 2 |
| 5 著しく大きな振動 | 15 | 9 |

振動の後に挙動の指標が正常走行の上位 1% を超えたイベントは、ヨーで 2.8%・操舵で 1.4%・
横ずれで 2.4% だった。正常走行で同じ値は定義上 1% なので、振動の大半は挙動に表れていない。

## 5. 代表ケース (上位 5 地点)

いずれも映像での確認はまだ。「観測」はデータから読める事実、「解釈」は推測。

### #1 08-15--09-01 seg21 29.15〜29.57 s (117 km/h、地点 0)

- 観測: 上下 ±6〜7 m/s²、ロール +10 → −16 deg/s。右前輪の後に右後輪が揺れ、
  その時間差 0.08 s はホイールベース/車速 0.08 s と一致。左側の輪速の揺れは右側の約 1/9。
  振動開始の約 0.1 s 後にブレーキが入り、前後 G −0.9 m/s²、車速は約 3 km/h 低下。
  振動後 1 秒以内にハンドルが +2.7° → −2.7° と振れ (最大 18.7 deg/s)、ヨー残差は最大 0.9 deg/s。
  舵角どおりの進路からの横ずれは 0.19 m
- 解釈: 右側の車輪だけが段差か落下物を踏んだ。同じ地点を通った 7 ドライブのうち
  振動が出たのはこの 1 回だけで、常設の段差ではない可能性がある。
  ブレーキが振動とほぼ同時に入っているので、運転者が前方に何かを見つけて制動した可能性もある
- 自動運転に必要な判断: 路上の落下物・穴の検知と、避けるか減速して通過するかの判断。
  片側入力後のヨー外乱の抑制
- データとしての価値: 評価データ候補 (挙動変化あり・再現しない一回性の事象)

### #2 08-17--14-55 seg9 54.04〜54.59 s (64 km/h、地点 19)

- 観測: 右前輪 → 右後輪の時間差 0.17 s (予想 0.15 s)、右側の揺れが左の約 6 倍。
  振動後にハンドルが約 +3° 動き (最大 13.8 deg/s)、ヨー残差が振動。
  舵角どおりの進路から右へ 0.39 m ずれ、GPS でも同じ向きに 0.24 m
- 解釈: 右車輪の通り道にある恒常的な凹凸。同じ地点・同じ向きで 5 ドライブ中 4 ドライブに振動が出ている
- データとしての価値: 同じ路面での再現性を評価する素材

### #3 08-03--10-35 seg10 18.22〜18.89 s (103 km/h、地点 20)

- 観測: 右カーブの途中 (ヨー −3 deg/s) で、振動中にハンドルが −10° → −2.5° と
  急に戻る (振動中最大約 35 deg/s)。その後カーブを抜ける。輪速の左右差は 2 倍で、片側の根拠は弱い
- 解釈: カーブの出口での通常の操舵戻しと振動が重なっただけの可能性がある。
  振動による舵の取られかどうかは、このデータからは分けられない

### #4 08-01--21-13 seg8 38.69〜39.73 s (110 km/h、夜間、地点 39)

- 観測: ロール +6 → −4.5 deg/s。輪速は右後輪だけ単発で揺れる。
  CAN からの横ずれは −1.6 m だが、GPS では +0.5 m で向きが合わない。
  振動前 3 秒にハンドルを −10° 切って戻す操作がある
- 解釈: 横ずれの値は単軌道モデルのずれに引きずられている可能性が高く、信頼度は低い

### #5 08-02--08-34 seg37 36.12〜37.79 s (110 km/h、地点 57)

- 観測: 振動中にハンドル +10° (最大約 40 deg/s)・ヨー 4.8 deg/s の急な操舵があり、
  すぐ戻している。右側の輪速は 0.7 s に、左側は 2.3 s に揺れる。約 3 秒後に減速 (前後 G −1.2 m/s²)
- 解釈: 急な操舵と路面の凹凸の通過が重なっている。車線変更検出には掛かっていない。
  操舵が振動への反応なのか、別の理由による操作なのかは分からない

## 6. 限界と未確認事項

- 映像での路面状態の確認は未実施。どのケースも路面が原因だとは確定していない
- comma2k19 は openpilot を載せた車両で記録されている。操舵の補正が運転者によるものか、
  openpilot の車線維持制御によるものかは区別できない (`docs/comma2k19_data.md` 4.5)
- 単軌道モデルは定常状態のモデルで、操舵の立ち上がりで残差が出る。カーブの出入りと重なると
  ヨー残差・横ずれが大きめに出る (#3・#4)
- GPS (`global_pose`) による横ずれと CAN による横ずれの相関は 0.13 で、サブメートルの裏付けには使えない
- 輪速の揺れは全体に右側が大きい傾向がある (振動イベント全体の中央値で右 1.4 倍)。
  路肩側の路面が荒いのか、センサ側の差なのかは未確認
- IMU の取付部の共振は否定できていない。ただし CAN の輪速も同時に揺れているイベントは、
  共振だけでは説明できない
- 走行路は CA-280 の高速道路と、その出入口付近だけ
- 輪荷重・サスペンション力は CAN・IMU で観測できず、推定もしていない
- しきい値 (A ≥ 3、上位 1%、左右差 2 倍など) は暫定で、映像確認の結果で見直す
