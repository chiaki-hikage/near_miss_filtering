# ヒヤリハット候補のイベント定義

`configs/detection.yaml` に定義した **23 種類**の一覧。
閾値の根拠と検討の経緯は [near_miss_filters.md](near_miss_filters.md)、
データセットごとにどれが動くかは [datasets.md](datasets.md) を参照。

数値は本文書ではなく `configs/detection.yaml` が正。ここは読むための要約。

## 0. 前提 — 判定より前の処理

| 項目 | 値 | 意味 |
|---|---|---|
| 再サンプル | 20 Hz | CAN の受信時刻は揺れるので、微分の前に必ず一様グリッドへ載せる |
| 両端の切り落とし | 0.6 s | 平滑化が端で不正な値を出すため |
| 欠測 | 埋めない | 受信間隔が 0.5 s を超えた区間は NaN のまま下流へ渡す |
| 平滑化 | 車速 0.25 s / 舵角 0.15 s / 縦加速度 0.25 s / 輪速 0.3 s | |

主な特徴量の作り方。

| 記号 | 定義 |
|---|---|
| `ax_mps2` | 車速の微分。平滑化 0.25 s |
| `ay_kin_mps2` | **`v × yaw_rate`**。横加速度計 (`ay_can`) は路面カントと混ざるので主系列にしない |
| `jerk` / `lat_jerk` | 上記をさらに 1 回微分。単独では判定に使わず、候補行の参考値として添える |
| `THW` / `TTC` | レーダで選んだ先行車まで。自車速 5 m/s 未満では算出しない |
| `yaw_residual_sigma` | 線形単軌道モデルの期待ヨーレートとの差を、車種ごとの残差標準偏差で割った値 |
| `beta_model_deg` | 定常単軌道モデルから出す重心位置の横滑り角 [deg]。`l_r·yaw/v − k·a_y`。光学式センサの実測と σ 0.99° で一致する ([kit_msdm.md](kit_msdm.md))。**低速では狭い旋回の幾何で大きくなるので、危険の指標に使うなら速度で門を掛ける**。現時点で検出器には未使用 |

**旋回除外 gate** (複数のイベントが共有): 前後 3 秒の正味方位角
`net_heading_win_deg` が 15 度未満。左折・ランプ・長いカーブを落とし、
「出て戻る」動きだけを残す。

## 1. イベント定義

`重み` はスコア計算に使う係数。閾値ちょうどで 1.0 となる超過量に掛かる。

| 分類 | イベント | 判定条件 | 重み | 想定状況 |
|---|---|---|---|---|
| **縦方向** | `hard_brake` 急ブレーキ | `ax < -2.5 m/s²` が 0.3 秒以上 | 1.0 | 急制動、前方事象への強い減速 |
|  | `hard_accel` 急加速 | `ax > +2.5 m/s²` が 0.3 秒以上 | 0.4 | 急加速、急な発進・速度回復 |
|  | `panic_brake` 急反応制動 | `ax > +0.3` から 1.5 秒以内に `ax < -3.0 m/s²` へ。0.2 秒以上継続 | 0.4 | 驚愕・緊急反応による急制動 |
|  | `panic_brake_pedal` ペダル急制動 | アクセル 5% 以上 → 0.5 秒以内に 1% 未満へ → 1.5 秒以内にブレーキ (立ち上がり 8 以上、無ければブレーキスイッチ) かつ `ax < -2.5` | 1.0 | 運転者が危険を認知して急制動 |
| **横方向** | `hard_steer` 急操舵 | `\|steer rate\| > 25 deg/s` ＋ `\|ay_kin\| > 2.0` ＋ `\|ay_can\| > 1.4 m/s²` の連言 (許容ずれ 0.3 秒)。0.15 秒以上。**旋回除外 gate ＋ v > 5 m/s** | 0.3 | 急な回避操舵、車線変更中止など |
|  | `lateral_accel` 横加速度過大 | `\|ay_kin\| > 3.0 m/s²` が 0.2 秒以上。**旋回除外 gate ＋ v > 5 m/s** | 0.3 | 急な横運動、回避操作候補 |
|  | `weaving` 蛇行 | 左右交互の振れが 3 回以上、`\|ay_kin\| ≥ 1.0` かつ `\|steer rate\| ≥ 8 deg/s` で裏付け、2〜8 秒、正味方位角 8 度以内で復帰、v > 10 m/s | 0.5 | 蛇行、連続的な修正操舵 |
|  | `counter_steer` 逆操舵 | `\|yaw\| ≥ 3 deg/s` かつ `\|steer rate\| ≥ 15 deg/s` で**符号が逆**。0.2 秒以上。**v > 10 m/s ＋ 旋回除外 gate** | 0.3 | 挙動立て直し、スリップ修正候補 |
|  | `yaw_instability` ヨー応答異常 | 単軌道モデルの期待ヨーレートから `6σ` 以上乖離が 0.3 秒以上。**v > 10 m/s ＋ 旋回除外 gate** | 1.5 | 車両姿勢の乱れ、スリップ・不安定挙動候補 |
| **前方接近** | `short_thw` 車間時間過小 | `THW < 0.6 s` が 0.5 秒以上 | 1.0 | 前車との車間が非常に短い |
|  | `low_ttc` TTC 過小 | `TTC < 2.0 s` が 0.3 秒以上 | 1.5 | 衝突余裕時間が小さい急接近 |
|  | `cut_in_candidate` 割込み | 先行車の入れ替わりで距離が 5 m 以上跳ぶ、または 10 m 以上縮む。40 m 以内に現れ 0.8 秒持続し、直後の `THW ≤ 0.8 s`。v > 8 m/s | 1.5 | 他車の急な割込み |
|  | `closing_fast` 急接近 | **同一の先行車**で `THW` が `-0.4 s/s` より速く縮小、かつ `THW ≤ 1.5 s`。0.5 秒以上。**v > 15 m/s** | 1.2 | 前車への急速な接近 |
| **車線変更** | `lane_change_candidate` 車線変更候補 | 左右一組のヨー振れ (各 1.5 度以上、間隔 3 秒以内)、推定横変位 2〜6 m、正味方位角 2.5 度以内で復帰。1〜8 秒、v > 10 m/s | 0.2 | 通常の車線変更候補 |
|  | `risky_lane_change` 危険な車線変更 | 車線変更候補の前後 2 秒に `short_thw` / `low_ttc` / `cut_in` / `closing_fast` / `hard_steer` / `lateral_accel` / `hard_brake` / `abs_active` / `vsc_active` / `aeb_active` / `wheel_speed_anomaly` のいずれかが共起 | 2.0 | 車間逼迫や急操作を伴う車線変更 |
| **複合回避** | `s_evasion` S 字回避 | 振れが 3 つ以上、`\|ay_kin\| ≥ 2.0 m/s²`、横に 1.2 m 以上ふくらみ最後に 1.0 m 以内へ戻る。1〜5 秒、v > 10 m/s | 2.0 | 障害物を避けて元の進路へ戻る |
|  | `brake_and_steer` 制動＋操舵 | `hard_brake` の前後 1 秒に `hard_steer` か `s_evasion` | 2.0 | ブレーキを掛けながら障害物回避 |
|  | `brake_after_evasion` 回避後制動 | `s_evasion` / `hard_steer` の 0〜3 秒後に `hard_brake` | 2.0 | 回避操作後の追加制動 |
|  | `panic_brake_with_lead` 前方要因付き急制動 | `panic_brake` の前後 2 秒に `short_thw` / `low_ttc` / `cut_in` / `closing_fast` | 2.0 | 前方車両への緊急反応 |
| **車両安全系** | `abs_active` ABS 作動 | ABS 作動フラグの**立ち上がり** | 2.0 | タイヤが制動限界に近づき ABS 介入 |
|  | `vsc_active` VSC 作動 | VSC 作動フラグの**立ち上がり** | **2.5** | 横滑りへの車両制御介入 |
|  | `aeb_active` PCS/AEB 作動 | Pre-Collision 作動フラグの**立ち上がり** | 2.5 | 車両側が前方衝突リスクを検知 |
|  | `wheel_speed_anomaly` 輪速異常 | 4 輪速差から旋回分 (`\|yaw\| × トレッド幅`) と区間中央値を引いた超過が 0.4 m/s 以上。**かつ** `\|ax\| ≥ 1.5` / ヨー残差 3σ / ABS 作動のいずれかが 0.5 秒以内に裏付け。v > 5 m/s | 1.5 | タイヤスリップ、ロック等の候補 |

## 2. 候補へのまとめ方とスコア

イベントは単体では出力しない。近いものをまとめて「確認する 1 区間」にする。

| 項目 | 値 |
|---|---|
| 前後の余白 | 2.0 s |
| 統合する間隔 | 2.0 s |
| 同種イベントの扱い | 種類ごとに最大値だけを採る (連発しても加算しない) |
| 共起ボーナス | 種類数 − 1 に 0.5 を掛けて加算 |
| 1 イベントの上限 | 3.0 |

`severity = Σ(種類ごとの最大スコア) + 0.5 × (種類数 − 1)`。
1 種類のスコアは `重み × min(1 + 超過量 / 閾値, 3.0)` で、**閾値ちょうどで重みそのもの**になる。

候補行には `t_peak` (最も強いイベントの中心時刻) が付く。`t_start` は余白を含むので、
頭出しには `t_peak` / `peak_segment` / `peak_t_in_segment_s` を使う。

## 3. 元の表からの修正点

- **`vsc_active` は未実装ではない。** `configs/detection.yaml` に定義があり、
  `TOYOTA_RAV4_TSS2` では 0x226 の `VSCACT` を復号している。重みは全 23 種で
  `aeb_active` と並ぶ最大の 2.5。ただし commaCarSegments 2,000 セグメント
  (33.3 h) の実測では **0 件**だった。「実装が無い」のではなく「まだ出ていない」
- `panic_brake` の起点は「正側」ではなく `ax > +0.3 m/s²`
- `hard_steer` / `lateral_accel` の gate には旋回除外だけでなく `v > 5 m/s` も入る
- `counter_steer` / `yaw_instability` の下限速度は `v > 10 m/s`
- `closing_fast` は `THW ≤ 1.5 s` かつ `v > 15 m/s` の条件も持つ
- `s_evasion` はふくらみと復帰だけでなく、振れ 3 つ以上と `\|ay_kin\| ≥ 2.0 m/s²` も要る
- `risky_lane_change` の共起先には `lateral_accel` と車両安全系 3 種、
  `wheel_speed_anomaly` も含まれる

## 4. 網羅性

`configs/detection.yaml` の 23 種類はすべてこの表にある。
入力が無いデータセットでは、該当する検出器は例外を出さず静かに 0 件になる
(どれが動くかは [datasets.md](datasets.md) §3a、実測件数は §3b)。

なお **`s_evasion` は 3 データセット・計 50 時間でまだ 1 件も出ていない。**
条件が厳しすぎる可能性があり、閾値の見直し候補として残っている。
