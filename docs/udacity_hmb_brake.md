# Udacity CH2_002 (HMB) の下り坂の制動と熱負荷 (2026-11-19)

[brake_fade_datasets_round2.md](brake_fade_datasets_round2.md) の第 1 候補を取得して調べた。前方映像付きの実走行で、下り坂の反復制動の熱負荷を、制動の信号と並べて確かめるのが目的。

**結論**:
- HMB_2 には峠越えの下り (201 m、3.8 km、平均 3.0°、急な所で約 4°、239 s) があり、前方映像・ペダル・ブレーキトルク・車速・IMU・高度がそろう。代表の場面の動画を作った。
- ブレーキの熱負荷は低い。直前 300 s のブレーキの仕事は最大 352 J/kg で、100 km/h からの停止 0.9 回分。comma2k19 の RAV4 の最大 (873 J/kg) の 0.4 倍。CH2_002 の 5 本の中ではこれが最大。
- 下りの位置エネルギーのうち、ブレーキに入ったのは 18%。残りは駆動側の負のトルク (44%) と空気・転がりの抵抗 (38%) に入った。
- 1 回ごとの制動の利きは、熱の指標とともに下がっていない (順位相関 +0.71、12 回)。熱負荷が低いので、フェードかどうかは判定しない。

## 2. HMB_2 の信号 (791 s)
| 必要なもの | 話題・項目 | 頻度 | 単位 (bag の型の定義のコメント) |
|---|---|---|---|
| ブレーキペダル | `/vehicle/brake_report` の `pedal_output` | 50 Hz | 単位なし、0.15〜0.50 |
| ブレーキトルク | `/vehicle/brake_info_report` の `brake_torque_actual` | 50 Hz | Nm (下の注意) |
| 駆動側のトルク | 同 `wheel_torque_actual` | 50 Hz | Nm (負 = エンジンブレーキか回生。区別できない) |
| 車速 | `/vehicle/wheel_speed_report` (4 輪) | 100 Hz | rad/s。`steering_report.speed` (m/s) との比で実効半径 0.332 m |
| IMU | `/imu/data` (Xsens、姿勢あり)、`/vehicle/imu/data_raw` | 400 Hz、100 Hz | |
| 高度 | `/fix` (400 Hz)、`/pressure` (気圧、50 Hz) | | |
| 前方映像 | `/center_camera/image_color/compressed` | 20 Hz | JPEG |
| ABS | `brake_info_report.abs_active` | | HMB_2 では一度も作動していない |

すべての話題で `header.stamp` と bag の記録時刻の差の中央値は 1 ms 未満。DBW は作動しておらず (`enabled` は常に 0)、人が運転している。

## 3. 方法 (`scripts/brake/udacity_hmb_heat.py`、設定 `configs/brake/udacity_hmb.yaml`)
1. **勾配**: `/fix` の高度 ÷ 走行距離 (前後 15 m ずつ)。
   - 気圧の高度から出した勾配と相関 0.987、差の中央値 0.29°。
   - Xsens の姿勢のピッチとは相関 0.49 にとどまる。急なカーブの間に大きく振れ、取り付けの傾き (約 −1.2°) と前のめりも混ざるので、勾配には使わない。
2. **力のつり合い**: a + g sin θ = kw·Tw − kb·Tb − c0 − c2·v²。2 段で当てはめる。
   - kw・c0・c2 はブレーキを踏んでいない時刻で当てはめた。R² は 0.971。kw から出る車重は 1,941 kg で、ありうる値。
   - kb は熱の少ない制動の時刻で当てはめた。R² は 0.63 (熱の多い制動の時刻では 0.82)。
   - **注意**: kb/kw = 0.73。`brake_torque_actual` を「Nm」のまま車輪の制動力とみなすと、実際の減速の約 73% しか説明できない。信号の中身 (圧力からの推定かどうか) は公開情報では分からないので、kb を実測から決めて使う。この比は bag によって 0.34〜0.97 とばらつく (制動の少ない bag ほど当てはめが不安定)。
3. **熱の指標**: ブレーキの仕事率 = kb·Tb·v (W/kg)。E300 は直前 300 s の和、H300 は時定数 300 s の 1 次遅れ (comma2k19 と同じ定義)。減速度から出した版 (勾配・駆動・抵抗を引いた減速度 × 車速) も並べた。
4. **1 回ごとの制動**: brake_torque_actual が 30 Nm 以上で 1.5 s 以上続き、峰が 100 Nm 以上のもの。定常の部分で次の 2 つを測る。
   - 利き η = 実測のブレーキの減速度 ÷ kb·Tb。
   - ペダルからトルクへの比。

## 4. 結果

### 4.1 下りのエネルギーの行き先 (HMB_2、281〜520 s、`descent_energy`)
| 行き先 | J/kg | 位置エネルギーに対する割合 |
|---|---|---|
| 位置エネルギーの減り (201 m) | 1,974 | 100% |
| ブレーキ | 351 | 18% |
| 駆動側の負のトルク | 875 | 44% |
| 空気・転がりの抵抗 | 758 | 38% |
| 駆動側の正のトルク (加えた分) | 116 | |
| 運動エネルギーの増え | 45 | |
| 残り (つり合わない分) | 60 | 3% |

平均の車速は 57 km/h。ブレーキを踏んでいた時間は下りの 35%。

### 4.2 熱の指標 (5 本の比較、`20261119_r16_udacity_HMB_*_heat`)
| bag | 長さ | 高度の幅 | E300 の最大 (J/kg) | 100 km/h の停止の回数 | 制動の回数 |
|---|---|---|---|---|---|
| HMB_1 | 221 s | 8〜124 m | 2 | 0.01 | 0 |
| **HMB_2** | 791 s | −1〜229 m | **352** (減速度からの版 428) | **0.91** | 12 |
| HMB_4 | 100 s | 48〜182 m | 0 | 0 | 0 |
| HMB_5 | 213 s | 60〜233 m | 127 | 0.33 | 9 |
| HMB_6 | 371 s | −20〜114 m | 305 | 0.79 | 8 |

比べる物差し:
- 100 km/h からの停止 1 回 = 386 J/kg。
- comma2k19 の RAV4 の最大 = 873 J/kg (2.3 回分)。

### 4.3 1 回ごとの制動の応答 (HMB_2、12 回、`brake_events.csv`)
- **利き η**: 熱の少ない 8 回の中央値は 1.14、熱の多い 4 回 (H300 ≥ 200 J/kg) は 1.32。熱の指標との順位相関は +0.71。下りの後半ほど高く、下がってはいない。
  - η が 1 より上に出るのは、kb を立ち上がりと戻りの時刻も含めて当てはめたため。定常の部分だけで測ると高めになる。比べるのは η どうしの比。
- **ペダルからトルクへの比**: 中央値は 5,519 (熱の少ない制動) と 5,992 (熱の多い制動) で、順位相関は +0.16。
- **ABS**: 一度も作動していない。
- **判断**: 熱の指標の最大は 100 km/h の停止 1 回分に届かない。利きが上がる向きの差は、勾配の誤差 (0.3° で約 0.05 m/s²) や踏み方の違いと区別できない。フェードの兆候とも、温まって利きが上がったとも言わない。

## 6. 限界
- **ブレーキの温度・圧力**: 記録が無い。熱の指標は仕事の和で、温度ではない。
- **brake_torque_actual**: Nm の値をそのまま制動力に使うと減速を約 27% 小さく見積もる。熱の指標は実測の減速で校正した kb で出している。
- **駆動側の負のトルク**: エンジンブレーキか回生かを区別できない。車両がハイブリッドかどうかも公開情報では確かめていない。
- **規模**: 下りは 1 本 (201 m) だけ。乗用車がフェードに近づく長い下り (数百 m 以上を連続して下る) とは規模が違う。
