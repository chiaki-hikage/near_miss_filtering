# TartanDrive 2.0: 振動の候補の人のレビュー (手順と準備したもの)

2026-11-17。`docs/offroad_tartandrive2_candidates.md` で取り出した候補のうち、次の 42 件を人がレビューする。

**目的:** 通常の荒れた路面の振動と、車両の挙動への影響を伴う振動を、どこまで分けられるかを確かめる。検出の閾値の調整ではなく、取り出した事象の妥当性の評価を先にする。

## 4. 偽の異常の点検 (自動、`20261117_r22/review_list.csv` の `q_*` 列)

**点検した項目** (te の −4〜+3 s で見た):

| 項目 | 偽の異常になりうる理由 |
|---|---|
| racepak の補正の状態の継ぎ目 | 前の段で直した混ざりは無くなったが、継ぎ目の前後 1 s は捨てたか抜けている |
| 状態が相関で決まらなかった窓 | 補正が前後の窓からの埋め合わせで、誤りうる |
| racepak の抜け | 1 → 0 の継ぎ目では 1 s 抜ける |
| ブレーキの飛び値 (6,000 以上) | 衝撃の近くで出やすい |
| 後輪の回転の 1 点の飛び値 | 中央値フィルタを越えた残り |
| IMU の抜け | 下の注意を参照 |
| GPS の速度の飛び | |
| ストロークの鏡写しの振れ | 補正の誤りを直した後に残るもの |

**結果:**
- 品質の注意が付いたのは、段 C で 11/22 件、段 A で 5/20 件だった
- 段 C に多いのはブレーキの飛び値 (6 件) である。衝撃の近くで出やすい、という前の段の見立てと合う
- **IMU の抜けの近くの候補 (要注意):** 124 件のうち 4 件 (A092・A108・A109・A122) で、te の ±5 s に 5〜25 s の IMU の抜けがある。レビューの対象では V32 (段 C) と V38 (段 A) がこれに当たる。
  - 重み付けは周波数領域で掛けるので、抜けの境目 (直線でつないだ所) の影響が前に漏れうる
  - 前後 ±30 s の中央値に抜け (振動が 0 に見える区間) が入るので、比が大きく出うる
  - **この 4 件は、偽の異常の可能性を否定できない**
- **時刻補正の影響を受ける指標:** 補正したのは racepak (ストローク・車輪の回転・ブレーキ・スロットル) だけである。
  ヨー・ロールの手がかりは IMU と GPS の姿勢から出しているので、racepak の時刻補正の誤りの影響を受けない。
  影響を受けうるのは、後輪の回転の左右差の手がかりと、運転操作の手がかりである

**自動の状況の値の割り振り** (旋回中 = ヨー角速度の 0.5 Hz 以下の平均が 10 deg/s 以上、斜面 = ロール角かピッチ角が 5° 以上):

| 群 | 直進・平地 | 旋回中を含む | 斜面・登り下りを含む |
|---|---|---|---|
| C | 14 | 4 | 5 |
| A | 16 | 3 | 1 |

複数に当たる件があるので、合計は群の件数と合わない。

## 5. レビューの項目 (選択肢は閲覧ページと同じ)

| 項目 | 選択肢 | 決め方 |
|---|---|---|
| 路面の原因が映像で見えるか | 見える / 見えない / 不明 | 画像の範囲 (衝撃の前の 0.5〜3 s) に、入力の原因と言える地形が写っているか |
| 原因 | 凹凸・わだち / 段差・縁 / 溝・くぼみ / 岩 / 斜面の乗り越え / 草・茂みで隠れる / その他 / 不明 | 見える場合だけ |
| 車両の挙動 | 振動だけ / 旋回に伴う / 斜面に沿う / 姿勢・向きが乱れる / 不明 | 時系列の 3・5 段と軌跡で決める。旋回・斜面で説明できる動きは「旋回に伴う」「斜面に沿う」。説明できない速い乱れが「姿勢・向きが乱れる」 |
| 運転から予想できる動きか | 予想どおり / 予想外 / 不明 | 速度・舵角・地形から見て、運転者が予想していた動きか |
| 信号の偽の異常の疑い | なし / あり / 不明 | 品質の注意や、物理として説明しにくい形 (片方の信号だけが跳ねる、鏡写し、段差状の飛び) |
| 安全に関わりそうか | 関わらない / 関わりそう / 不明 | 横転・逸脱・接触につながりそうか。判断の材料が無ければ「不明」 |
| 判断の確かさ | 高 / 中 / 低 | |
| メモ | 自由 | |

**判断できないものは無理に分類しない。** 次のような場合は「不明」を選ぶ。
- 草や茂みで地面が見えない
- 逆光でよく見えない
- 衝撃の瞬間が車体の下で写らない

評価では「不明」を分母から外し、外した数も出す。

## 6.3 ブレーキとアクセルの信号の入れ替わり (2026-11-18)

racepak の `/controls` (型 `racepak/rp_controls`) は、型の定義では `throttle`・`brake` の順で、KITTI の列も同じ順である (bag のメッセージと KITTI の値が一致することを確かめた)。
ところが、データの振る舞いは名前と逆だった (全 45 走行。racepak の時刻は補正済み)。

| 列 (定義の名前) | 振る舞い | 判断 |
|---|---|---|
| 0 列目 (`throttle`) | ふだん約 11.5 で止まる。急減速 (前後の加速度 ≤ −1.3 m/s²) の 45% で 15 を超える (一定速では 4%)。加速度との相関は弱い負 (中央値 −0.15) | ブレーキ |
| 1 列目 (`brake`) | 加速度と正の相関が 45 走行中 44 (中央値 r ≈ 0.44)。加速が約 0.8 s 遅れて続く。急減速中の中央値 105・一定速 222・加速中 255 | アクセル |

**対応:** 設定 `reaction.controls_cols` を `{brake: 0, throttle: 1}` とし、`td2_vibration_poc.pedals` で読むようにした。単位はどちらも確かめていない。6,000 以上の飛び値は 1 列目 (アクセル) に出る。

**作り直したもの** (追加の取得なし):

| 実行 ID | 中身 |
|---|---|
| `20261118_r6` | 候補の特徴づけ (列を直した版) |
| `20261118_r7` | レビューの対象 42 件 (r22 と同じ選び方・同じ番号で、品質の注意の文言を直した) |
| `20261118_r8` | 42 件の閲覧ページと動画 |
| `20261118_r9` | 長め・10 枚/s の 5 件 |

**V18 の読み直し:**
- ブレーキはずっと 0% 近くで、運転者はブレーキを踏んでいない
- アクセルは 60〜80% から衝撃の直前に戻し、衝撃の約 0.5 s 後に 100% まで踏み直している
- 衝撃のあとの急減速 (−3.0 m/s²) は、ブレーキではなく、衝撃とアクセルを戻したことによる
- 状況の欄からは「ブレーキあり」「衝撃のあとのブレーキ」が消えた

## 6.4 5 件の車体のイラストの動画と、急ブレーキ・急操舵の兆候 (`20261118_r13`)

- **急減速:** はっきりしているのは V18 だけで、ブレーキではなく衝撃とアクセルを戻したことによる
- **向きの急な変化:** V12 だけ。画像では砂利道から右の草の土手へ出て戻る動きで、アクセルも踏んだままなので、予定した動きの可能性が高い。ただし舵角が使えないので、操舵かどうかは確かめられない
- **運転者の反応の手がかり:** アクセルを戻す動き (V18・V02・V42) だけである

    --result <書き出した review_result.csv> --run-id <新しい ID>

| 問い | 見る値 |
|---|---|
| 段 C と段 A を、人の判断で分けられるか | 群ごとの「姿勢・向きが乱れる」「予想外」「安全に関わりそう」の割合 (Wilson の 95% 区間付き) |
| ヨー・ロール・左右輪速差の手がかりがそろうことの識別力 | 手がかりの数 (0〜3) ごとの「姿勢・向きが乱れる」の割合と順位の AUC。比べるために、振動の大きさ (MTVV)・突出の度合い (前後との比) の AUC |
| 手がかりごとの当たり外れ | 「姿勢・向きが乱れる」を正とみたときの適合率・再現率 |
| 旋回・斜面と予期しない挙動を分けられるか | 自動の状況 (旋回中・斜面) と人の「旋回に伴う」「斜面に沿う」の対応 |
| 偽の異常が残っていないか | 品質の注意と、人の「偽の異常の疑い」の対応 |

**件数が少ないことに注意:** 段 C 22 件、段 A 20 件しかない。割合の区間は広い (たとえば 10/20 なら 95% 区間は 0.30〜0.70)。差がはっきりしないときは、群の差より、手がかりの数ごとの傾きと個々の件のメモを見る。
