# 片側路面入力による異常振動 PoC 最終まとめ (comma2k19 RAV4)

**目的**: 路面の高さを数値で推定することではなく、片側の路面入力による異常振動を定性的に検出し、説明できるかを確かめる。
**結論**: 振動が片側の入力か左右同時の入力かは、IMU のロールと CAN 輪速の左右差から判別でき、映像の舗装の状態とも矛盾しなかった。
ただし、振幅・継続時間・衝撃直前の波形はモデルと合わず、凹凸の高さ・形・凹みか突起かは断定できない。
**ヒヤリハットは確認できていない。** 挙げた事象はいずれも「振動起因のロングテール候補」にとどまる (4 章)。

## 1. 物理モデル

![モデル](../out/vibration/final/model_schematic.png)

| 項目 | 内容 |
|---|---|
| モデル | 線形 7 自由度 (車体の上下・ピッチ・ロール + 4 輪のばね下)。スタビライザー、IMU の取付位置、タイヤの浮き (接地荷重 ≥ 0) を含む |
| 車両パラメータ | 公開諸元と仮定値で固定 (`configs/vibration_fullcar.yaml`)。今回の比較では一切動かしていない |
| 路面入力 | 単発の凹凸 (1−cos、長さ 0.5 m)。前輪が当たり、ホイールベース/車速 (L/v) の後に後輪が当たる |
| 3 仮説 | 左右対称 (両輪) / 右側入力 (右前 → 右後) / 左側入力 (左前 → 左後) |
| 当てはめ | 上下加速度の振幅と時刻だけ。**ロール・ピッチは当てはめに使わず、予測として実測と比べる** |
| 判別の原理 | 左右対称ならロールは厳密に 0。片側入力では、ロールの最初の向きが入力の側と、凹みか突起かで決まる (右表) |

新しいモデルの実装やパラメータの調整はしていない。比較は既存の関数を呼び出すだけのスクリプトで行った。

## 2. 代表イベントでの 3 仮説の比較

| 事象 | 場所 | 車速 | 選んだ理由 |
|---|---|---|---|
| 08-15 seg21 | 高速道路 | 115 km/h | 振動の大きさが全体で 1 位。右側が強い |
| 08-17 seg9 | 地点 19 (一般道の交差点)、縁石側の車線 | 64 km/h | 同じ地点を 7 回通過したうち、右側が強かった走行 |
| 08-17 seg41 | 地点 19、内側の車線 | 55 km/h | 対照 (同じ交差点で左右がそろって揺れた走行) |

![波形](../out/vibration/final/three_hypotheses_waveforms.png)

![整合性](../out/vibration/final/three_hypotheses_matrix.png)

| 事象 | CAN 輪速の揺れ 右/左 | 前輪 → 後輪の時間差 (L/v) | 実測のロール/上下 | 片側仮説の予測 | 最も整合する仮説 |
|---|---|---|---|---|---|
| 08-15 seg21 | **5.4** | 0.05 s (0.08 s) | 2.9 | 2.7 | 右側入力 |
| 08-17 seg9 | **4.3** | 0.19 s (0.15 s) | 1.8 | 2.6 | 右側入力 |
| 08-17 seg41 | 0.7 | 0.22 s (0.18 s) | 0.7 | 2.4 | 左右対称に近い (一部に左右差) |

ロール/上下は、ロール角速度 [deg/s] と上下加速度 [m/s²] の RMS の比。数値は `out/vibration/final/three_hypotheses.csv`・`wheel_evidence.csv` にある。

**合ったところ**

- **ロールの大きさ**: 右側の 2 事象では、実測のロール/上下の比が片側仮説の予測の 0.7〜1.1 倍に収まった。左右対称の仮説では 0 になる。
  seg41 では、実測の比が片側仮説の予測の 0.3 倍しかなく、左右対称に近い
- **側**: CAN 輪速の揺れは右側が 4〜5 倍だった。輪速は IMU と独立した信号で、ロールから判断した側と一致した
- **時刻**: 右前輪から右後輪への時間差は L/v と ±0.04 s で一致した。前輪と後輪が同じ通り道を順に通ったことと合う
- **ロールの波形**: 時間のずれを 0 に固定すると、右側仮説との相関は +0.48・+0.51 (左側仮説では −0.48・−0.51) だった
- **ピッチ**: どの仮説でも予測の最初の向き (機首上げ) は実測と同じだった。ピッチは左右対称の seg41 で最もよく合い、相関は +0.66 だった

**合わなかったところ**

- **衝撃の直前の前ぶれ**: seg21 と seg9 では、上下加速度で決めた当たり時刻の 0.05〜0.25 s 前に、ロールがまず右下がりに +7〜10 deg/s 振れた。
  右側の突起という仮説では、最初は左下がりになるはず。この間のハンドル角の変化は 1° 程度、横加速度の変化は 0.1 m/s² 未満なので、操舵では説明できない。
  右側の凹み・段差を下りる動き・継ぎ目の溝のような形なら最初の向きは合うが、上下加速度の当てはめは突起を選んでいる。
  単発の 1−cos という形が、実際の路面と合っていない
- **時刻の自由度**: ±0.15 s の時間ずれを許すと、逆側 (左側) の仮説でも相関が +0.42〜+0.83 まで上がる。
  ロールの波形だけでは側を決められず、輪速の左右差とロールの大きさが判断の根拠になる
- **継続時間**: 実測では約 11 Hz の振動が 0.35〜1.65 s 続く。モデルでは前輪と後輪の 2 回の短い衝撃 (0.2〜0.3 s) にしかならない
- **振幅**: 上下加速度に合わせると、高さ 4〜10 cm の突起が必要になり、タイヤが 33〜66 ms 浮く。
  地点 19 では、舗装の状態に合わせた路面モデル (`docs/vibration_pavement_site19.md`) でも、現実的な高さ (帯域 RMS 10 mm) では
  8〜15 Hz の振幅が実測の 27〜45% にとどまった

## 3. 映像との照合

![車輪の通り道](../out/vibration/final/wheel_tracks_video.png)

映像に、平坦な路面と直進を仮定して左右の車輪の通り道を投影した。○ は、前輪が振動の開始時刻に通る位置。
カメラの高さ・地平線の行は、地点 19 の白線から当てはめた値 (高さ 1.0 m、焦点距離 910 px) を、別のドライブの seg21 にも流用した。

| 事象 | 映像で見えるもの | 片側入力が疑われる根拠 |
|---|---|---|
| 08-15 seg21 | 自車線は明るいコンクリート、右隣の車線は暗いアスファルト。その境目が暗い帯 (継ぎ目) になっている | 右輪の通り道が、舗装の境目の継ぎ目とほぼ重なる。左輪の通り道は一様なコンクリート |
| 08-17 seg9 | 停止線を越えた先に、色の違う四角い補修区画。区画の中に暗い斑点 (穴または補修跡) | 右輪は補修区画の中、斑点の近くを通る。左輪は区画の左端付近 |
| 08-17 seg41 (対照) | 交差点内のひび割れたアスファルト。横方向のひびが車線をまたぐ | 左右の通り道に同じような横断方向のひびがかかる。左右同時の入力と矛盾しない |

**断定できない理由**

| 理由 | 内容 |
|---|---|
| 高さが映像から分からない | 暗い帯・斑点が凹みなのか、色が違うだけなのかを区別できない。2 章の「突起か凹みか」の矛盾も解消できない |
| 車輪位置の誤差 | カメラの横位置は記録が無く、車両中心と仮定した。カメラの高さも当てはめの下限 (1.0 m) に張り付いており、地平線の行と分けて決まらない。横方向の誤差は ±0.3 m 程度を見込む。継ぎ目や斑点の幅と同じくらい |
| 時刻の誤差 | 映像の白線から求めた入口の時刻には ±0.05 s (地点 19 で約 1 m) の幅がある。上下加速度から決めた当たり時刻も ±0.1 s ずれうる |
| 平坦・直進の仮定 | seg21 では自車が右へ寄っている途中で、投影した通り道は近似にすぎない |
| 原因が 1 つに決まらない | 振幅が足りない原因が、路面ではなく車両側 (4 章) にある可能性を除けていない |
| 1 回だけの事象 | seg21 は同じ地点を 7 回通ったうち 1 回だけ振動した。路面ではなく落下物だった可能性も残る |

## 4. 定量的な不一致と、検証に必要な情報

| 不一致 | 考えられる原因 | 必要な追加センサ・信号・パラメータ |
|---|---|---|
| 振幅が足りない (現実的な高さで 8〜15 Hz が実測の 27〜45%) | ばね下の減衰がモデルより小さい。ブッシュ・マウントによる高周波の伝わり。IMU の取付部 (フロントガラスのブラケット) の増幅 | ばね下 (ナックル) の加速度計、車体フロアの加速度計 (取付部の影響と分けるため)。ダンパーの減衰特性、ばね下質量、タイヤの上下剛性の実測値 |
| 11 Hz の振動が 0.5〜1.5 s 続く | 減衰の小さいばね下共振。または路面の凹凸が区間として続いている | ばね下の加速度計またはサスペンションのストロークセンサ。路面プロファイル (レーザープロファイラや MMS による左右別の縦断形状) |
| 衝撃前の右下がりのロール (凹みか突起か) | 継ぎ目の溝・段差を下りる形で、1−cos の突起では表せない | 左右別の路面プロファイル。ストロークセンサ (伸び・縮みの向きから凹みか突起かが直接分かる) |
| 当たり時刻が ±0.1 s 定まらない | IMU と CAN の時刻ずれ (ヨーレートで約 21 ms、輪速は 1〜91 ms の幅で未確定)。映像からの推定の誤差 | 共通の時刻で記録したログ。輪速センサの生パルス、または高い周期の輪速 |
| 車輪の横位置が ±0.3 m 定まらない | カメラの取付位置・姿勢が記録されていない。GPS の精度不足 | カメラの外部パラメータ (高さ・横位置・姿勢)。RTK-GNSS。車線内の横位置 |
| 0.5〜3 Hz の車体応答、15〜30 Hz のピッチが合わない | 慣性モーメント・重心高・IMU 位置が仮定値。積載状態が不明 | 車両の慣性・重心高の諸元。IMU の取付位置の実測。乗員・積載の記録 |
| 輪荷重・サスペンション力が分からない | CAN・IMU では観測できない | ホイール 6 分力計 (研究用)、またはタイヤセンサ。RAV4 2017 の CAN に車高・ストロークの信号があるかは未確認 |

**ヒヤリハットの評価**: 確認できていない。

- 08-15 seg21: 振動の約 0.1 s 後にブレーキが入り、ハンドルが ±2.7° 振れた。振動後のヨーレート残差は正常走行の上位 0.3%、
  操舵速度は上位 1.4% にあたる。ただし、右隣の車両の割り込みと重なったケースとされており、振動への反応か割り込みへの反応かは区別できない
- 08-17 seg9: 振動後のヨーレート残差は正常走行の上位 0.4% だったが、操舵 (+3°) と横ずれ (0.39 m) は上位 1% に入らない
- どちらも、操舵が運転者によるものか openpilot の車線維持制御によるものかが分からない。周囲の交通 (レーダ) もまだ見ていない

## 5. まとめ

| 問い | 答え |
|---|---|
| 片側入力の異常振動を検出できるか | できる。ロール/上下の比と CAN 輪速の左右差が、IMU と CAN の独立した 2 つの根拠になる |
| モデルで定性的に説明できるか | 側 (右か左か両方か)、前輪 → 後輪の順序と時間差、ロールの大きさの比は説明できる。継続時間・衝撃直前の波形・凹みか突起かは説明できない |
| 映像と合うか | 片側と判断した 2 事象では、右輪の通り道に舗装の境目・補修区画があった。左右同時と判断した事象では、左右に同じようなひびがあった。いずれも矛盾はしないが、高さが見えないため断定はできない |
| 路面の高さを推定できるか | できない。振幅が数倍合わないので、推定すれば系統的に過大になる |
