このデータセットは**候補の抽出対象ではない。物差しとして使う。**
comma 系のデータでは横滑り角 β が推定器のノイズ床に埋もれて検証できなかった
([comma1M.md](comma1M.md))。ここには光学式センサで実測した β が 1000 Hz で入っており、
横方向の限界まで走っている。

### 使わない信号

`v_cog_mps` と `beta_cog_mps` は「重心位置の速度と横滑り角」とされているが、
Correvit の v_x/v_y と公開されている並進ベクトルから**再現できなかった**。

- `v_cog` は定常直進でも `|v_cor|` より 1〜1.5 m/s 大きい
- 11 本中 1 本 (`dynmic_asphalt_b_cobble_1`) で `beta_cog` の符号が Correvit 由来の β と逆
- 単位は名前の `_mps` ではなく rad

別系統 (RTK GNSS/INS か推定器の出力) と思われる。定義が確認できるまで使わない。
**真値として使うのは `v_x_cor_mps` / `v_y_cor_mps` だけ。**

### 車両諸元 (`parameter.m`)

```
ホイールベース 3.0 m   トレッド 1.65 m   質量 2254 kg
ヨー慣性 2193 kg·m²    l_f 1.563 / l_r 1.437 m   重心高 0.4 m
動的タイヤ半径 0.36 m  コーナリング剛性 前後とも 234,008 N/rad
座標系 ISO 8855 (x 前・y 左・z 上)
Correvit → 後軸 [0.958, -0.159, 0] m、後軸 → 重心 [1.437, 0, 0] m
```

`l_f > l_r` で重心が後ろ寄り、前後の剛性が同じなので
**安定係数 Kus = -0.000405 rad·s²/m とオーバーステア傾向**。
本プロジェクトの RAV4 は Kus = +0.00235 (アンダーステア) で、性格が逆である。

## 2. ファイルの読み方 — scipy では読めない

各信号は MATLAB の `timeseries` オブジェクト (MCOS) として保存されている。
`scipy.io.loadmat` は MCOS を不透明オブジェクトとしてしか返さず、数値を取り出せない。

実体は同じファイルの `__function_workspace__` の中に、
**(時刻ベクトル, データ) の対が struct のフィールド順に並ぶ**形で入っている。
`src/near_miss/io/kit_msdm.py` はそこを直接走査して読む。

対応付けが正しいことは、毎回次の 3 点で検証している。

1. 対の前半が 0 から始まる単調増加であること
2. 時刻とデータの長さが一致すること
3. すべての信号の時刻ベクトルが同一であること

## 4. 検証結果

`scripts/validate_sideslip_kit.py` の出力。

### A. 符号の取り決めは一致している

| 組み合わせ | 相関 |
|---|---:|
| 舵角 δ と ヨーレート | **+0.962** |
| ヨーレート と `ay_kin` (= v × yaw) | **+0.956** |
| 舵角 δ と 重心位置の β | +0.937 |

ISO 8855 (y 左が正) と本プロジェクトの「左が正」は一致する。**符号の直しは不要。**

3 つ目が正なのは、50 km/h 以下では幾何の項が支配的で β が舵角と同符号になるため。
速度が上がるとタイヤの横滑りの項が勝って逆符号へ移る。

### B. `ay_kin = v × yaw_rate` は限界域でも使える

後軸位置の実測 `a_y` と直接比べた（微分を挟まないので比較自体にノイズが乗らない）。

- 相関 **r = 0.9904**、誤差 中央値 −0.035、**σ 0.671 m/s²**

| \|β\| | 秒 | 誤差 σ [m/s²] |
|---|---:|---:|
| 0–2° | 251.8 | 0.767 |
| 2–4° | 192.8 | 0.646 |
| 4–6° | 128.2 | 0.581 |
| 6–8° | 61.1 | 0.559 |
| 8–10° | 25.7 | 0.539 |
| 10°– | 65.8 | 0.645 |

**誤差は β が大きくなっても増えない。** むしろ僅かに減る。
`lateral_accel` / `hard_steer` / `s_evasion` が `ay_kin` を土台にしていることは、
横滑りが大きい領域でも問題ない。

### C. ヨー残差は横滑りの検出器ではない

線形単軌道モデルの期待ヨーレート `v·δ/(L + Kus·v²)` と実測の差。

- 全体で 中央値 +0.45 deg/s、σ 4.82、|最大| 53.0

| \|β\| | 秒 | 残差 σ [deg/s] |
|---|---:|---:|
| 0–2° | 251.8 | **6.38** |
| 2–4° | 192.8 | 4.60 |
| 4–6° | 128.2 | 3.34 |
| 6–8° | 61.1 | 2.63 |
| 8–10° | 25.7 | 2.23 |
| 10°– | 65.8 | 2.63 |

**残差は β が大きいほど小さい。** 何に反応しているかを調べると:

| 相手 | 相関 |
|---|---:|
| 速度 | **+0.621** |
| \|ヨーレート\| | +0.243 |
| \|舵角レート\| | −0.065 |
| \|β\| | −0.333 |

**残差は速度に反応している。** 定常モデルなので、過渡と高速域でずれるのは当然である。
commaCarSegments でヨー残差の上位 10 件がすべて低速・高舵角レートの
モデル適用範囲外だったこと ([comma_car_segments.md](comma_car_segments.md)) と整合する。

したがって **`yaw_instability` を「横滑り・不安定挙動の候補」として扱うのは誤り**である。
実体は「定常単軌道モデルが合わない区間」であり、そう呼ぶべきである。

### D. β は CAN で取れる量だけから出せる

定常単軌道モデルから、**v / ヨーレート / 横加速度の 3 つだけ**で重心位置の β を出す。

```
beta = l_r · yaw_rate / v  -  (m · l_f / (C_r · L)) · a_y
```

3 つとも commaCarSegments で復号済みの信号である。

| | 値 |
|---|---|
| 相関 | **r = 0.9865** |
| 回帰 | 傾き 1.048 / 切片 +0.25 |
| 誤差 | 中央値 +0.18°、**σ 0.99°**、\|最大\| 5.4° |

| \|β\| | 秒 | 誤差 σ [deg] |
|---|---:|---:|
| 0–2° | 251.8 | 1.24 |
| 2–4° | 192.8 | 0.89 |
| 4–6° | 128.2 | 0.77 |
| 6–8° | 61.1 | 0.75 |
| 8–10° | 25.7 | 0.74 |
| 10°– | 65.8 | 0.75 |

**誤差は β の大きさによらずほぼ一定**で、±19° の範囲で 1° 以内に収まる。

閾値判定の性能:

| 判定 | 適合率 | 再現率 |
|---|---:|---:|
| \|β\| ≥ 3° | 0.834 | 0.978 |
| \|β\| ≥ 5° | 0.832 | 0.963 |
| \|β\| ≥ 8° | 0.884 | 0.969 |

#### 幾何の裏取り

実測 β がどの位置でモデルと一致するかを当てはめると、
**Correvit から前方 2.50 m** で残差最小になった。
公開されている Correvit → 重心の距離は **2.395 m** で、10 cm 差で一致する。

これは同時に重要な注意でもある。**β は計測点で大きく変わる。**
Correvit 位置のまま重心のモデルと比べると、相関が −0.93 と符号すら合わない。

### E. 車両諸元の誤差にどれだけ耐えるか

他車種へ持ち込むとき、`C_r` (コーナリング剛性) は分からない。そこがどれだけ効くか。

| 条件 | 相関 | 誤差 σ [deg] | 適合率(5°) | 再現率(5°) |
|---|---:|---:|---:|---:|
| 公称 | 0.9865 | 0.99 | 0.832 | 0.963 |
| C_r を 1.5 倍 | 0.9791 | 1.37 | 0.757 | 0.986 |
| C_r を 0.5 倍 | 0.9892 | 0.94 | 0.988 | 0.824 |
| **第2項を落とす (幾何のみ)** | 0.9604 | **2.22** | **0.483** | 0.998 |
| l_r を 0.9 倍 | 0.9884 | 0.87 | 0.916 | 0.888 |
| l_r を 1.1 倍 | 0.9846 | 1.46 | 0.696 | 0.996 |

**C_r が 2 倍ずれても σ は 0.94〜1.37° に収まる。** 一方、
**第2項 (タイヤの横滑り) を落とすと適合率が 0.48 まで落ちる**ので、省略はできない。

つまり `C_r` は雑な見積りで足りるが、項そのものは要る。

## 5. 本プロジェクトへの反映

| 分かったこと | 対応 |
|---|---|
| 符号規約は ISO 8855 と一致 | 変更不要 |
| `ay_kin` は限界域でも σ 0.67 m/s² | `lateral_accel` / `hard_steer` / `s_evasion` はこのままでよい |
| ヨー残差は横滑りではなく速度に反応する | **`yaw_instability` の位置づけを見直す。** 速度依存の正規化か、速度帯別の閾値が要る |
| β は v / yaw / a_y から σ 1° で出せる | **新しい特徴量として追加できる。** commaCarSegments の 3,148 時間に適用可能 |
| C_r の誤差には鈍感 | 車種ごとの諸元が揃わなくても持ち込める |

## 6. commaCarSegments への適用結果

`beta_model_deg` を `features.py` に実装し、TOYOTA_RAV4_TSS2 の 2,000 セグメント
(33.3 時間) に掛けた。

### 車種ごとの係数の出し方

質量もコーナリング剛性も分からないので、当てはめ済みの安定係数から出す。

```
k = l_f * Kus / (l_r - l_f)          (C_f = C_r を仮定)
```

KIT の公称諸元で照合すると、公称の `m*l_f/(C_r*L)` = 0.005018 に対して
この式は 0.005024 を返し、**0.1% で一致**する。

| | RAV4 TSS2 | RAV4 (2017) | IONIQ 5 (KIT) |
|---|---:|---:|---:|
| L [m] | 2.69 | 2.66 | 3.0 |
| l_f [m] | 1.1835 | 1.1704 | 1.563 |
| Kus [rad·s²/m] | +0.001794 | +0.00235 | −0.000405 |
| **k [s²/m]** | **0.006573** | **0.008617** | 0.005024 |

**l_f は実測値ではない。** rlog の `carParams.centerToFront` をそのまま使っているが、
その値は openpilot が Toyota 各車に置いている「ホイールベースの 0.44 倍」という
既定値である (2.6899 × 0.44 = 1.1836)。`l_r − l_f` は近い 2 数の差なので
l_f の誤差が k に増幅されて効くが、k が 2 倍ずれても β の誤差は 1.4° 以内に
収まることを §4 E で確かめてある。

### 横加速度センサの読みについて

第 2 項には **車体固定の横加速度センサの値** (`ay_can_mps2`) を入れる。
`ay_kin = v × yaw_rate` を入れると式が v と yaw_rate だけの関数に潰れ、
横滑りの情報が消えるので使えない。

路面のカントがある区間ではセンサは重力の分だけ小さく読むが、
**タイヤの横力も同じだけ小さい**ので、モデルの入力としてはセンサ値が正しい。

TSS2 の 2,000 セグメントで測った回帰は

```
ay_can = 0.799 * ay_kin + 0.183      (r = 0.965, v>10 m/s, |ay_kin|>1 の 17,741 点)
```

comma2k19 (CA-280 の高速のみ) では 0.678 だった。**路線が限定されない TSS2 の方が
1 に近い**ので、この差はセンサのスケール誤差ではなく路面のカントで説明がつく
([signals_rav4.md](signals_rav4.md) の未確定事項に対する一つの答え)。
残る 20% ぶんが β に与える誤差は、横加速度 4 m/s² の場面で 0.3° 程度。

### 結果 — 速度で性格が変わる

| 速度帯 [m/s] | 秒 | p0.1 | p99.9 | 最大 | **\|β\| > 5° の割合** |
|---|---:|---:|---:|---:|---:|
| 3–5 | 3,405 | −14.50 | 17.63 | 18.81 | **16.19%** |
| 5–10 | 13,630 | −7.30 | 7.28 | 9.50 | 1.98% |
| 10–15 | 19,026 | −1.33 | 1.28 | 2.28 | **0.000%** |
| 15–20 | 18,185 | −0.45 | 0.30 | 0.60 | 0 |
| 20–25 | 13,458 | −0.55 | 0.40 | 0.93 | 0 |
| 25–30 | 17,798 | −0.66 | 0.50 | 0.70 | 0 |
| 30–60 | 18,846 | −0.54 | 0.44 | 0.85 | 0 |

**低速の大きな β は失陥ではなく、狭い旋回の幾何そのものである。**
v = 3 m/s でヨーレート 25 deg/s なら第 1 項だけで
`1.5065 × 0.436 / 3 = 0.219 rad = 12.5°` になる。駐車場や交差点の切り返しであって、
危険挙動ではない。**β を危険の指標に使うなら速度で門を掛けること。**

`v ≥ 10 m/s` に限ると、**33.3 時間を通じて |β| は 2.66° を超えなかった。**
上位 12 セグメントはすべて v = 10.0〜10.6 m/s の帯の下端で、
ヨーレート 20〜28 deg/s・横加速度 2.6〜4.7 m/s² の通常の旋回だった。

### 分かったこと

commaCarSegments の RAV4 TSS2 には**大きな横滑りは入っていない**。
これは「33.3 時間で VSC が 1 度も作動しなかった」という
[comma_car_segments.md](comma_car_segments.md) の結論を、
**別系統の、しかも実測で較正済みの指標が独立に裏付けた**ことになる。

### ここからどう実装したか

当初は `|β| ≥ 4°` かつ `v > 10 m/s` という単一の閾値イベントを考えていたが、
そのままにはしなかった。β は線形モデルの出力なので「大きい β」が
「異常な β」を意味せず、単一閾値では上の表の低速帯を落とすか、
高速帯で 0 件になるかのどちらかにしかならないためである。

代わりに、**1 次 (β の大きさで粗く拾う) → 2 次 (幾何・舵で説明できるぶんを
引いても残るかを見る)** の 2 段フィルタとして `configs/detection.yaml` の
`sideslip` 節に入れた。定義と実測結果は [sideslip_filter.md](sideslip_filter.md)。

このデータセットはそこでも**物差し**として使っている。dynamic run 13 本を
抽出側とまったく同じ経路に通し、実測 β を答え合わせだけに使って再現率を測る
(`scripts/validate_sideslip_filter.py`)。結果は 13/13 の走行が候補を出し、
実測 `|β| ≥ 5°` の 192.7 秒を **100%** 覆った。

この物差しは設計そのものも変えた。当初 2 次フィルタは「横力 ∧ 舵で説明できない
∧ 信号の整合 ∧ 持続時間」の必須 AND だったが、このデータと突き合わせて

* 横力の条件で実測の横滑り 2 区間 (v = 4 m/s、|β| 6.3〜6.5°、
  横加速度 0.7〜1.1 m/s²) が落ちていた
* 舵で説明できない条件は**定常のドリフト中に効かない** (定常 80.5% /
  過渡 97.5%)。舵と車両の応答がつり合ってしまうため

ことが分かり、両方を必須から信頼度 (項目数で数える方式) へ移した。
再現率 98.9% → 100%、公道側の候補増は 33 → 34 件だった。

ただし §6 の表のとおり KIT の限界走行は速度が低く、`v ≥ 10 m/s` かつ
`|β| ≥ 5°` の時間は 851 秒中 0.1 秒しかない。上の再現率は適用範囲の下限を
3 m/s に下げて測った値であり、**配備時の設定 (v ≥ 10) での再現率は
このデータでは測れない**。

## 7. 限界

1. **42 分しかない。** うち限界走行は 14.5 分。統計を取る母数ではない
2. **1 台・1 銘柄のタイヤ・乾燥のみ・50 km/h 以下**
3. **限界走行に輪速が無い。** 輪速由来の特徴量は検証できない
4. **ESC / VSC のフラグが無く、作動状態の記載も無い**
5. **映像が無い**
6. `beta_cog_mps` / `v_cog_mps` の定義が再現できていない
7. IONIQ 5 はオーバーステア傾向 (Kus < 0)、RAV4 はアンダーステア傾向 (Kus > 0)。
   **β の第2項の係数は車種ごとに出し直す必要がある**
8. **限界走行がすべて低速** (中央値 7.4 m/s、最大 15.6 m/s)。
   横滑りフィルタの再現率を高速域で確かめる用途には使えない
