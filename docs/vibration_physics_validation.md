# 映像で路面特徴が見えた振動地点の物理的整合性 (7 自由度 Full-car モデル)

`docs/vibration_locate_candidates.md` の上位 20 地点のうち、前方映像で路面特徴が見えた 7 地点について、
「映像の路面入力の種類・左右」と「実測の上下・ロール・ピッチ・輪速」が、既存の 7 自由度モデルの物理として整合するかを確かめた。

**路面の高さは当てはめていない。** 車両パラメータも `configs/vibration_fullcar.yaml` のまま一切動かしていない。

## 結論

| 地点 | 映像 | 物理モデルから見た入力 | P1 左右 | P2 L/v | P3 比 | P4 3-8 Hz | P5 11 Hz | P6 再現 | 判定 |
|---|---|---|---|---|---|---|---|---|---|
| 344 | 補修跡 (右輪) | 右片輪 | true | true | true | true | true | true | **Strong** |
| 44 | 補修跡・穴 (右輪) | 右片輪 | true | true | true | uncertain | uncertain | true | **Strong** |
| 327 | 補修跡 (右輪) | 2 イベントで右と食い違いが 1 件ずつ | true | true | true | true | true | false | **Strong** |
| 46 | 補修跡・ひび (右輪) | 右片輪 | uncertain | true | true | true | true | true | Partial |
| 226 | 亀裂の多い路面 (両輪) | 右片輪 | false | true | true | false | true | true | Partial |
| 15 | 横方向の継ぎ目 (両輪) | 右片輪 (ロールは左寄り、輪速は右) | uncertain | uncertain | false | true | uncertain | true | Partial |
| 10 | 横方向の継ぎ目 (両輪) | 右片輪 | false | true | false | uncertain | true | true | Not explained |

- **右輪の補修跡 4 地点は、物理的に右片輪の入力として説明できた。** 輪速 (普段比) とロール (IMU) という独立な 2 つの信号が、どちらも右側を示した。
  前輪 → 後輪の時間差は L/v と合い、ロール/上下・ピッチ/上下の比も片側入力のモデルと 0.5〜2 倍に収まった
- **横方向の継ぎ目 2 地点と荒れた路面 1 地点は、映像では「両輪」に見えたが、車両応答は右片輪に近かった。**
  とくに地点 10 は 8 回の通過すべてで、ロールと輪速の両方が右を示した。
  継ぎ目の右輪側だけが傷んでいる可能性があるが、確かめていない。「左右同時」の単純な入力では説明できない
- 3 つの「Strong」も、振幅・8〜15 Hz の継続時間・0.5〜3 Hz の成分は合っていない (5 章)。合ったのは向き・順序・時間差・比・主周波数である

## 1. 対象と方法

### 1.1 対象

`out/vibration/locate/review_video.csv` の判定が「一致」の 7 地点。同じ車線でイベントが出た全通過 (2〜8 件、計 35 件) を評価し、地点の判定は多数決にした。
映像上の通り道は平坦・直進の仮定で描いた推定なので、映像の左右の確度はすべて「中」とした。

### 1.2 モデル入力

`scripts/vibration/validate_sites_with_fullcar.py`、設定は `configs/vibration_physics_validation.yaml`。

| 種類 | 与え方 |
|---|---|
| A 右だけ | 右前輪 → L/v 後に右後輪 |
| B 左だけ | A の左右反転 |
| C 左右同時 (継ぎ目) | 左右前輪が同時 → L/v 後に左右後輪。変形として、斜め (15°、片側が トレッド × tan15° 遅れる) と左右で深さが違うもの (片側 0.5 倍) も試した |
| D 荒れた路面 | 左右独立の ISO 8608 クラス B の荒れ。長さは実測の 8〜15 Hz 振動の継続 × 車速 (1〜6 m)、乱数 10 通り |
| 形状 (A〜C) | 1−cos の凹み・突起 (0.5 m)、継ぎ目の溝・盛り上がり (0.15 m)、段差 (上り)、正弦波パルス (0.6 m) |
| 高さ | 1・2・3 cm。モデルは線形なので比・符号・時刻・周波数は高さによらない。振幅の幅と、タイヤが浮く高さを見るためだけに使った |

形状は、上下の 3〜8 Hz の波形相関 (振幅によらない) が最も高いものを選んだ。
モデルは、実測と同じ方法で検出した当たり時刻に合わせた。時刻を自由にずらしてはいない。

**輪速はモデルに無い。** 各輪のタイヤ荷重の変動を、輪速と同じ帯域 (2〜15 Hz) に通して代わりに使った。比べるのは左右の比と時間差だけで、振幅は比べていない。

### 1.3 側の指標 (ロール角速度と上下速度の相関)

既存の判定 (ロールの最初の向き) は、凹みか突起かで符号が逆になるうえ、どちらかを上下の波形から決めると通過ごとに揺れた。
代わりに、3〜8 Hz に通した**ロール角速度と上下速度 (上下加速度の積分) の相関**を使った。

| 入力 | モデルでの値 (30〜110 km/h、全形状) |
|---|---|
| 右だけ | −0.73〜−0.95 |
| 左だけ | +0.73〜+0.95 |
| 左右同時 | 0 |

右前輪が突起に乗ると車体は右側から持ち上がり、上下は上向き、ロールは左下がりになる。凹みなら両方とも逆になる。
どちらの場合も符号は逆なので、この相関の符号は凹みか突起か・形状・車速・高さによらない (`tests/test_physics_validation.py` で確認)。
IMU だけから求まるので、輪速と独立に左右を判定できる。

### 1.4 段階評価

| 項目 | true の条件 (イベントごと) |
|---|---|
| P1 左右とロールの向き | 片側の映像: 輪速 (普段比) で映像の側が 2 倍以上強く、かつ側の指標が映像の側 (\|値\| ≥ 0.3)。片方だけなら uncertain、逆側を示せば false。両輪の映像: 輪速の差が 2 倍未満で、側の指標も \|値\| < 0.3 |
| P2 前後輪の時間差 | 強い側の前輪 → 後輪の輪速の揺れの時間差が L/v ± 0.05 s (± 0.10 s で uncertain) |
| P3 比 | 3〜8 Hz のロール/上下が、映像の入力の種類 (片側 / 左右同時 / 荒れ) のモデルと合い、ピッチ/上下がモデルの 0.5〜2 倍 |
| P4 3〜8 Hz | 上下の波形相関 ≥ 0.5 かつ、ロールかピッチの相関 ≥ 0.4 (±0.05 s のずれを許す)。荒れは 3〜8 Hz / 8〜15 Hz の比がモデルの 1/1.5〜1.5 倍 |
| P5 11〜12 Hz | 実測とモデルの主周波数 (6〜20 Hz) がどちらも 10〜13.5 Hz |
| P6 複数通過 | 地点の通過の 7 割以上で、輪速の強い側と、側の指標の符号がそろう |

P1〜P5 は地点のイベントの多数決 (true = 1・uncertain = 0.5・false = 0 の平均が 2/3 以上で true、1/3 以下で false)。
総合は、P1 と P3 が true で true が 4 つ以上かつ P1〜P4 に false が無ければ Strong、P1 と P3 がともに false か true が 1 つ以下なら Not explained、それ以外は Partial とした。

## 3. 路面特徴の種類別の傾向

| 種類 | 地点 | 期待した応答 | 実測 |
|---|---|---|---|
| 補修跡・穴 (右輪) | 344・44・327・46 | 右の輪速が強い、側の指標が負、ロール/上下が片側モデル並み、前→後輪が L/v | 4 地点とも期待どおり。46 は左右差が弱い (輪速 1.3 倍・側の指標 −0.20) |
| 横方向の継ぎ目 (両輪) | 15・10 | 輪速が左右対称、ロールが小さい、上下とピッチが大きい | **ロールが片側入力並みに大きい** (片側モデルの 0.8〜1.0 倍)。輪速は右が 2 倍強い。斜めの継ぎ目・左右で深さの違う継ぎ目 (比固定) では、15 の 6 通過中 1 通過しか説明できなかった |
| 亀裂の多い路面 (両輪) | 226 | 左右独立の荒れなので輪速もロールも左右に揺れる | ロール/上下は荒れのモデルの 1.8 倍、輪速と側の指標はともに右が強い。3〜8 Hz と 8〜15 Hz の比は荒れのモデルと合わない |

継ぎ目の 2 地点では、映像の「両輪」と車両応答の「右寄り」が食い違った。考えられる原因は 3 つある。

1. 継ぎ目の右輪側だけが段差や欠けになっている
2. 映像で見た継ぎ目とは別の右側の凹凸が、振動の主因である
3. 地点 10 は 117 km/h で 0.5〜3 Hz の上下・ピッチが大きく (3〜8 Hz に比べてモデルの 10 倍)、橋の取り付け部のような長い波長の入力が重なっている

どれかは、このデータからは決められない。

## 4. 右輪優位 (81%) との関係

### 4.1 映像一致 7 地点

- 映像で右輪の特徴が見えたのは 4 地点、両輪が 3 地点。左輪は 0 地点
- 35 通過すべてで輪速は右が強く (2 倍以上は 27 通過)、側の指標も 22 通過で右、3 通過で左だった
- 7 地点に限れば、「右側の路面入力が多い」ことと、輪速・ロールの右優位は整合した。
  ただ、映像の上位 20 地点そのものが輪速の右優位を含む指標で選ばれているので、この 7 地点から全体の割合は言えない

### 4.2 全 1,037 イベント

側の指標はモデルを使わず IMU だけで求まるので、全イベントで計算した (`all_events_side_index.csv`)。

| 輪速 (普段比) | 側の指標: 右 (≤ −0.3) | 左 (≥ +0.3) | 中立 |
|---|---|---|---|
| 右が 2 倍以上 (188 件) | 96 | 23 | 69 |
| 左が 2 倍以上 (23 件) | **0** | 14 | 9 |
| 差が 2 倍未満 (826 件) | 224 | 200 | 402 |

| | 輪速で右が強い | 側の指標が負 (右) |
|---|---|---|
| 全体 | 81% | 55% |
| 80 km/h 以上 (722 件) | 89% | 54% |
| 80 km/h 未満 (315 件) | 62% | 56% |

- 輪速とロールは、両方がはっきりした側を示すときにはほとんど食い違わない (輪速が左なら IMU が右を示した例は 0 件)。2 つの指標の相関は +0.35
- ただ、**IMU から見た右の入力は 55% で、輪速の 81% ほど偏っていない。** 高速道路ではとくに差が大きい
- 「右輪が路肩寄りの荒れた部分を踏みやすいため、右側のイベントが多い」という仮説は、IMU から見ると弱い右寄り (55%) までしか支持されない。
  輪速の 81% には、右輪の輪速の計測側の特性 (センサ・トーンリング・ばね下の左右差など) が混ざっている可能性がある。どちらかは確かめていない

## 6. 現行モデルで説明できない点

| 項目 | 実測 | モデル | 解釈 |
|---|---|---|---|
| 振幅 | 3〜8 Hz の上下は、2 cm の入力の 0.6〜21 倍 (上位 20 地点の代表通過) | — | 高さとしては大きすぎる。単発の凹凸だけでなく、周りの路面の荒れや長い波長の入力も 3〜8 Hz に入っている。振幅で高さを議論できない理由になる |
| 8〜15 Hz の継続時間 | 中央値 0.85 s (映像一致 7 地点)、1.1 s (上位 20 地点) | 0.26 s・0.28 s (実測/モデルの中央値 2.6 倍・3.9 倍) | 現行モデルの 11 Hz のモード (減衰比 0.33〜0.36) は実車より減衰が強すぎる。ただ、実測の継続 (約 1 s) に合う減衰比は 0.02 程度で、ばね下としては小さすぎる。IMU の取付部 (フロントガラス) の共振が重なっている可能性を否定できない |
| 0.5〜3 Hz の成分 | 3〜8 Hz に対してモデルの 3〜12 倍 (7 地点中 5 地点) | 短い凹凸では小さい | 長い波長の路面 (橋の取り付け部・うねり) の入力。短い代表形状の範囲外 |

| 前輪 → 後輪の時間差 | 中央値で L/v より 0.02 s 短い | L/v | 輪速の揺れのピークの取り方 (包絡線の最大) による偏りか、後輪側の応答の速さの違い。未確認 |
| 輪速の振幅 | km/h 単位の揺れ | モデルに輪速が無い | タイヤ荷重の変動で代用し、比と時刻だけ比べた |

一方、車体の固有振動の周波数は実測と近かった。ロールは実測 1.51 Hz (中央値) に対しモデル 1.71 Hz、上下は実測 1.56 Hz に対し 1.42 Hz。
主周波数 (6〜20 Hz) も、実測 11.9 Hz に対しモデル 11.1 Hz (映像一致 7 地点の 35 通過、窓内のピーク) で、11〜12 Hz の固有応答はモデルにも現れる。

## 7. 次に改善すべき車両パラメータ・計測

| 優先 | 対象 | 根拠 | 必要なもの |
|---|---|---|---|
| 1 | ばね下の減衰 (タイヤの減衰・ダンパーの高周波特性) | 8〜15 Hz の継続が 3〜4 倍長い | まず IMU 取付部の共振と切り分ける。車体 (またはハブ) に固定した加速度計、または停車中の打撃試験 |
| 2 | 輪速の応答モデル | 輪速の振幅と左右の感度差を比べられない。81% と 55% の差の原因を切り分けられない | 前後方向のタイヤ・サスペンションのコンプライアンス、有効転がり半径の荷重依存。左右の輪速センサの感度の確認 |
| 3 | ロールの剛性・慣性 | ロールの固有振動数がモデルで約 13% 高い | 公開諸元 (スタビライザー)。影響は小さい |
| 4 | 路面入力の形 (車両パラメータではない) | 0.5〜3 Hz の成分と継ぎ目のロール | 長い波長の入力・左右で違う入力を代表形状に足す。高さは当てはめない |

## 9. 限界

- 映像の判定は、Claude が 2 枚の静止画で行った暫定のもの。映像の通り道は推定で、左右の確度は「中」
- 車両は 1 台 (RAV4) だけ。車両パラメータは公開諸元と仮定値で、校正していない
- 側の指標が「右だけで負」になるのは、このモデルでの性質である。実車の IMU の取付位置・向きの誤差が大きければ変わりうる
- 判定のしきい値 (0.3・2 倍・0.5〜2 倍・±0.05 s など) はすべて暫定。結果を見ながら、2 回、判定の作りを直した (8〜15 Hz を外して 3〜8 Hz の比にした、ロールの向きを側の指標にした)
- 「Strong」は物理モデルとの整合を示すもので、路面の高さや形を推定できたことを意味しない。ヒヤリハットも確認していない
