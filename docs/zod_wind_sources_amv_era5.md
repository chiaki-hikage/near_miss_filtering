# 衛星の雲の動きによる風 (AMV) と再解析 (ERA5・CERRA) を、ZOD の横風の照合に使えるか

2026-11-12 の調査。対象は ZOD mini の 2 走行 (000000: スウェーデン 2022-02-14 13:19〜14:14 UTC、000002: ドイツ 2022-06-13 09:20〜10:58 UTC。`docs/zod_weather_poc.md`)。

- 調べたもの: EUMETSAT の資料と Data Store の公開カタログ (認証なしのメタデータ)、WMO WIS2・CEOS FedEO の目録、Copernicus CDS の公開カタログ API (認証なしのメタデータ)
- **データは取得していない** (AMV・ERA5・CERRA の値も、衛星画像も)。ZOD full も取っていない
- 既存のコード・結果・依存・ディレクトリは変えていない。この文書だけを追加した

## 0. 結論

| 問い | 答え |
|---|---|
| 1. 2022 年の Meteosat の AMV は使えるか | **Data Store では取れない。** Data Store の AMV は、再処理の記録 (CDR) が 2019-08 / 2020-04 まで、MTG の AMV が 2025-01 から。2022 年の運用の MSG AMV (`EO:EUM:DAT:MSG:AMV`、BUFR、1 時間ごと) は目録上 2004 年から続いているが、Data Store の一覧に無く、**EUMETSAT Data Centre への注文** (EO Portal の登録が要る) で取る見込み (未確認) |
| AMV の低高度・高度・品質・分解能 | 低高度の AMV は赤外・可視の雲の追跡で得られる (水蒸気チャンネルの低高度 AMV は無い)。高度は雲頂の気圧 [hPa] で、低高度は概ね 700 hPa より下 (地上 0.5〜3 km)。品質は QI (時間・空間・予報との整合) 0〜100。追跡の範囲は 24×24 画素 (直下で 72 km)、**ZOD の 2 地点では約 80×160〜200 km** (衛星の天頂角 60〜67°)。1 時間ごと (15 分間隔の 3 枚の画像から) |
| 2. ERA5 の 10 m 風と突風 | **取れる** (CDS の公開カタログで確認)。1 時間ごと、0.25°。10 m と 100 m の u・v、瞬間の突風 (i10fg)、前回の出力からの最大突風 (fg10、WMO の 3 秒突風)。CC BY 4.0。取得には CDS の利用者登録と API の鍵が要る。地点の時系列の製品 (`reanalysis-era5-single-levels-timeseries`、2024-12 まで) で、点ごとに小さく取れる |
| 追加: CERRA | 欧州の領域再解析、**5.5 km**。10 m の風速・風向、突風 (予報値だけ)、**地上 15〜500 m の 11 段の風**。2022 年を含む。CC BY 4.0。CDS の登録が要る |
| 3. 地上観測との比べ方 | §4。ERA5・CERRA は観測所の位置で、AMV は観測所の周り (100〜200 km、±30 分) で比べる。AMV は高さが違うので、ERA5 の気圧面の風を間に挟む |
| 4. AMV の高さと地上 10 m の違い | 低高度の AMV (0.5〜3 km) の風は、地上 10 m の風より、一般に **1.4〜2.5 倍強く、風向は 10〜40° 右 (北半球) に回る** (境界層の一般的な目安。データでは確かめていない)。**AMV から車の位置の 10 m の横風を推定するのは無理がある**。大きな流れ (その時間・地域の上空の風向と強さ) の確認にとどまる |
| 5. 既存の AMV を優先 | 既存の AMV (運用の MSG AMV) の取り方を確かめる段階。独自の雲の追跡は、§5 のとおり必要性が無いので行わない |
| 6. 量・ライセンス・認証・難しさ | §6 |

**推奨**: ZOD の車の位置の横風の目安には、**AMV ではなく ERA5 (と CERRA) を優先する**。理由は、(1) 全シーケンスの位置・時刻で値が得られる (観測所の近くでなくてよい)、(2) 地上 10 m の風と突風がそのままある、(3) 小さく取れる、(4) 利用条件が明確 (CC BY 4.0)。ただし再解析は観測ではなくモデルの値で、地点の突風は表せないので、まず SMHI・DWD の観測所 (取得済み) と比べて、どれだけ合うかを確かめる (§7 の PoC)。AMV は、その結果を見てから、上空の流れの確認に限って使うかを決める。

## 1. EUMETSAT の AMV

### 1.1 2022 年に使えるプロダクト

EUMETSAT Data Store の公開カタログ (`https://api.eumetsat.int/data/browse/1.0.0/collections`、2026-11-12 05:40 UTC、193 件) で、AMV を含むもの:

| コレクション | 内容 | 期間 | 2022 年 |
|---|---|---|---|
| EO:EUM:DAT:0405 | AMV CDR Release 2、MFG・MSG 0° | 1981-09-03〜2019-08-31 | × |
| EO:EUM:DAT:1082 | OCA AMV CDR Release 1、MSG 0° | 2004-01-19〜2019-08-31 | × |
| EO:EUM:DAT:1083 | SEVIRI Rapid Scan AMV CDR Release 1 (欧州の 5 分走査、高解像度の風) | 2008-05-06〜2020-04-03 | × |
| EO:EUM:DAT:0998 / 0676 | MTG (FCI) AMV、BUFR / netCDF | 2025-01-27〜 | × |
| ほかに AVHRR (極軌道) の AMV の CDR、Sentinel-3 SLSTR の AMV、ASCAT (海上の 10 m 風) | | | 陸上の道路には使えない・期間外 |

運用の MSG AMV:
- 目録 (WIS2: `urn:wmo:md:int-eumetsat:met10:amv`、CEOS FedEO: `EO:EUM:DAT:MSG:AMV`) では「Atmospheric Motion Vectors - MSG - 0 degree」、**期間 2004-01-29〜 (終わりなし)**、範囲 ±67.5°、BUFR、1 プロダクト 3〜5 万本、WMO のデータの区分は「core」
- Data Store の一覧には無い。Data Store の検索 API (`search-products`) で `pi=EO:EUM:DAT:MSG:AMV` を指定すると 404 だった
- → 2022 年の分は、**EUMETSAT Data Centre (EO Portal) の過去分の注文**で取ることになる見込み。注文できるか・期間・ファイルの大きさは、EO Portal に登録して確かめる必要がある (**未確認**)
- 利用条件: MTG の AMV は CC BY 4.0 と目録にある。MSG の運用 AMV の利用条件の文言は確かめられなかった (WMO の core データ)。注文の前に確かめる
- ほかの国の衛星の AMV (米国 GOES、日本ひまわり) は欧州を見ていない。極軌道 (Metop の AVHRR) の AMV は高緯度向けで、2022 年の運用の分は今回調べていない

### 1.2 MSG の AMV の作り方と性質 (AMV CDR Release 2 の利用者ガイド、EUM/OPS/REP/20/1191306。運用と同じ追跡の方法)

| 項目 | 内容 |
|---|---|
| 時間 | 1 時間ごと。15 分おきの画像から 3 つの中間の風を求め、平均する |
| 画素 | 直下で 3 km (SEVIRI の赤外) |
| 追跡の範囲 | 24×24 画素 (直下で 72 km)。15 分後の画像で、80×80 画素の範囲を相互相関で探す |
| チャンネル | 赤外 10.8 µm、水蒸気 6.2 µm (CDR)。運用は 5 チャンネル (目録)。**低高度の水蒸気 AMV は無い** (水蒸気チャンネルは低い雲を見ない) |
| 高さ | 雲頂の気圧 [hPa]。追跡に効いた画素の雲頂の高さの重み付き平均。不透明な雲は輝度温度と気温の鉛直分布の照合、半透明の雲は補正、低い雲は逆転層の扱いあり |
| 品質 | QI (0〜100): 3 つの中間の風の時間の整合、周りの風との空間の整合、予報との整合から。予報との整合を含む値と含まない値がある |
| 誤差 (ラジオゾンデとの比較) | 赤外の高・中層は −1〜−3 m/s の速さの偏り、**低層の赤外 AMV は +0.5 m/s 程度**。高さの割り当ての誤りが主な誤差の原因 |
| 範囲 | CDR は ±60° (緯度・経度)。運用の目録は ±67.5° |

### 1.3 ZOD の 2 地点での見え方 (幾何の計算。球の近似)

| 地点 | 衛星 (2022 年) | 天頂角 | 赤外の画素 (推定) | 追跡の範囲 24×24 画素 (推定) |
|---|---|---|---|---|
| 000000 (57.76 N, 12.82 E) | MSG 0° | 66.6° | 3.3 × 8.3 km | **約 80 × 200 km** |
| | MSG 欧州の 5 分走査 (9.5° E) | 65.7° | 3.3 × 8.0 km | 約 80 × 190 km |
| 000002 (52.20 N, 9.94 E) | MSG 0° | 60.4° | 3.2 × 6.6 km | **約 80 × 160 km** |
| | 5 分走査 | 59.7° | 3.2 × 6.4 km | 約 80 × 150 km |

- スウェーデンの地点は、CDR の範囲 (±60°) の外 (57.8 N は緯度では内側だが、天頂角が 66.6° と大きい)。運用の範囲 (±67.5°) の中
- 1 本の AMV は、80 × 160〜200 km の範囲の雲の動きの代表値。**観測所 (走行中の最寄りの中央値 8〜15 km) や ERA5 の格子 (約 15〜28 km) より 1 桁粗い**
- 低い雲の上に高い雲があると、衛星には高い雲しか見えず、低高度の AMV は得られない。000000 の映像 (`docs/zod_signals.md` §5) は曇りと雨で、雲が何層もある可能性がある (推定)

## 2. ERA5

CDS の公開カタログ API (`https://cds.climate.copernicus.eu/api/catalogue/v1/collections/...`、`/api/retrieve/v1/processes/...`、2026-11-12 に確認):

| 項目 | `reanalysis-era5-single-levels` | `reanalysis-era5-single-levels-timeseries` |
|---|---|---|
| 期間 | 1940-01-01〜2026-11-06 | 1940-01-01〜2024-12-06 |
| 時間・空間 | 1 時間ごと、0.25° (北緯 52〜58° で東西 15〜17 km × 南北 28 km) | 1 時間ごと、地点 (格子点の値) |
| 風の変数 | 10 m の u・v、100 m の u・v、瞬間の 10 m 突風 (`instantaneous_10m_wind_gust`)、前回の出力からの最大 10 m 突風 (`10m_wind_gust_since_previous_post_processing`。WMO の 3 秒突風の定義) | 10 m・100 m の u・v、前回の出力からの最大突風 |
| 利用条件 | CC BY 4.0 | CC BY 4.0 |
| 取得 | CDS の利用者登録、利用条件への同意、API の鍵 (`cdsapi`) | 同じ。範囲は `area` で指定 |

- ERA5 の突風は、モデルの物理による推定 (パラメタリゼーション)。1 時間の中のいつ起きたかは分からない
- Google Cloud の公開バケット (ARCO-ERA5、zarr、匿名で読める) にも ERA5 があるが、配布の形が全球の格子で、地点だけを小さく取るには向かない。公式の CDS を優先する

## 3. CERRA (欧州の領域再解析)

| 項目 | 内容 (CDS の公開カタログ) |
|---|---|
| 期間 | 1984-09-01〜2026-08-31 |
| 格子 | 5.5 km (高解像度)、欧州 |
| 時間 | 解析 3 時間ごと、予報 1 時間ごと (先行時間 1〜6 時間) |
| 風 | 単一レベル: 10 m の風速・風向 (解析と予報)、10 m 突風 (予報だけ、前回の出力からの最大)。**高さ別 (`reanalysis-cerra-height-levels`): 地上 15, 30, 50, 75, 100, 150, 200, 250, 300, 400, 500 m の風速・風向** |
| 利用条件 | CC BY 4.0 |
| 取得 | CDS の登録。**高さ別の製品は範囲 (`area`) を指定できず、欧州全体の場が来る** (1 場あたりの大きさは未確認) |
| 注意 | ECMWF の資料に、CERRA の 10 m 突風のメタデータの誤りの注記がある (2026-03)。使う前に確かめる |

CERRA は観測所 (5.5 km の格子) に近い細かさで、地上 15〜500 m の風を持つので、**地上 10 m と AMV の高さの間をデータで埋められる**のが利点。

## 4. 地上観測 (SMHI・DWD) との比べ方

すでに取得した観測 (`data/zod_weather/`): 8 観測所、2022 年全体 (SMHI は毎正時の 10 分平均、DWD は 10 分値と 1 時間値)。

| 比べるもの | 位置の合わせ方 | 時間の合わせ方 | 指標 |
|---|---|---|---|
| ERA5 10 m ⇔ 観測所 | 観測所に最も近い格子点 (と周り 4 点の内挿) | ERA5 の毎正時 ⇔ 観測所の毎正時の 10 分平均 (SMHI は同じ時刻、DWD は正時の 10 分値) | 風速の偏り・二乗平均の誤差・相関、風向の差 (風速 2 m/s 以上)、ベクトルの差。突風: ERA5 の fg10 (前 1 時間の最大) ⇔ 観測所の最大瞬間風速 (SMHI の 1 時間の最大、DWD の 10 分の最大を 1 時間で最大にしたもの) |
| CERRA 10 m ⇔ 観測所 | 同上 (5.5 km) | 3 時間ごとの解析、または 1 時間ごとの予報 | 同上。ERA5 より合うかを見る |
| 低高度の AMV ⇔ 観測所 | 観測所から 100〜200 km 以内の AMV (§1.3 の追跡の範囲) | AMV の時刻の ±30 分 | 気圧 700 hPa より下・QI ≥ 80 (予報との整合を含まない値も見る) の AMV。地上 10 m との直接の比較はしない。下の高さの補正を挟む |
| 高さの補正 | ERA5 の気圧面 (925, 850, 700 hPa) または CERRA の高さ別 (15〜500 m) の風で、AMV の高さの風と 10 m の風の比と、風向の回転を、その時刻・その場所で求める | 同じ時刻 | AMV を 10 m に下ろした値と観測所の差 |
| 横風成分 | 車の進む方位 (ZOD の衛星測位) で、それぞれの風を W_left = −W·sin(D − H) にする | | 観測所の間の幅 (mini で 2.3〜4.5 m/s、`docs/zod_weather_poc.md` §3.2) と、ERA5・CERRA・AMV の値の差を比べる |

統計は 2 走行の前後 3 時間だけでは足りないので、**観測所の 2022 年 2 月と 6 月の全時間** (観測は取得済み) で ERA5・CERRA と比べる。車の走行の時刻は、その中の例として示す。

## 5. AMV の高さと地上 10 m の違い

| 高さ | 気圧 (標準大気) | 地上 10 m の風との関係 (一般的な目安。**データで確かめていない**) |
|---|---|---|
| 10 m | 地上 | 観測所の風速計の高さ。ZOD の車の高さ (0.5〜2 m) はさらに弱い |
| 100 m | — | 対数則 (粗度 0.03〜0.5 m) で 10 m の 1.4〜1.8 倍 (ln(100/z0)/ln(10/z0) で計算) |
| 0.5〜1 km | 950〜900 hPa | 境界層の上部。地衡風に近づく。陸上では地上の風は地衡風の 0.4〜0.7 倍、風向は地上で 20〜40° 左 (北半球。上空ほど右に回る) |
| 1.5 km | 850 hPa | 低高度の AMV の多く。地上の風の 1.4〜2.5 倍 (上の 0.4〜0.7 倍の逆数)、風向は 10〜40° 違う |
| 3 km | 700 hPa | 低高度の AMV の上限の目安 |

- 地上 10 m の風は、地形・建物・森・防音壁で局所的に変わる。AMV の高さの風は、地域の大きな流れ
- 安定 (夜・冬) のときは、上空と地上の風が切り離され (地上は弱く、向きもずれる)、比が大きくなる。000000 は冬の昼の曇り、000002 は夏の昼
- **ZOD の車の位置の横風への役立ち方**: 低高度の AMV から 10 m の風を出すと、速さで 1.4〜2.5 倍、向きで 10〜40° の不確かさに、80×200 km の範囲の代表性が加わる。観測所の間の横風成分の幅 (2.3〜4.5 m/s) より小さくなる見込みはない。**横風の値の推定には使えず、「その時間・地域で強い風の流れがあったか」の確認に限られる**
- この幅は、§7 の PoC で ERA5 の気圧面・CERRA の高さ別の風を使って、その日・その場所の値として測れる

**独自の雲の追跡** (SEVIRI の画像から自分で AMV を作る) は、行わない。理由: (1) 運用の AMV と同じく雲の高さの風しか出ず、上の問題は変わらない、(2) 画像の量が大きい (SEVIRI の全円盤の画像は 15 分ごと)、(3) 高さの割り当てが難しい。NWC SAF の高解像度風 (HRW) のソフトウェアも同じ理由で後回し。

## 7. 小規模 PoC の計画 (実行は合意の後)

目的: ZOD の全シーケンスに付ける「その時刻・その位置の風の目安」として、ERA5・CERRA が観測所の観測とどれだけ合うかを測る。AMV は、上空の流れの確認として使えるかだけを見る。

1. **準備 (ユーザー)**: CDS の利用者登録と ERA5・CERRA の利用条件への同意、API の鍵の設定 (`~/.cdsapirc`)。AMV を試す場合だけ、EUMETSAT EO Portal の登録
2. **ERA5 (最優先)**: 8 観測所と 2 つの OXTS の地点の、2022 年 2 月・6 月の地点の時系列 (u10, v10, u100, v100, fg10)。観測所の観測と比べる (§4)。判断の目安 (仮): 風速の相関 0.8 以上、風向の差の中央値 30° 以内、突風の比の幅が観測所の間の差より小さい
3. **ERA5 の気圧面**: 2 走行の時刻の 925/850/700 hPa の風。10 m との比と風向の回転を、その日・その場所で求める (§5 の表をデータで置き換える)
4. **CERRA**: 取る量を確かめてから、10 m と 100 m だけを、2 走行の時刻の前後で取る。ERA5 より観測所に合うかを見る
5. **AMV (条件つき)**: 2〜4 の結果で、上空の流れの確認が要ると判断した場合だけ、EO Portal で 2022-02-14 13:00 と 2022-06-13 10:00 前後の MSG AMV の注文を試す。注文できない・量が大きい・利用条件が合わない場合は、やめて報告する
6. **ZOD への当てはめ**: OXTS の 50 s の位置・時刻で、ERA5 (と CERRA) の横風成分を求め、観測所からの横風成分 (`out/zod/weather/mini/match_oxts.csv`) と並べる
7. 成果物: `scripts/zod/` に取得と比較のスクリプト、`configs/zod/` に設定、`out/zod/weather_reanalysis/mini/` に結果、この文書の追記

full への広げ方: ERA5 の地点の時系列は、シーケンスの数 (1,473) に比例する小さな取得で、全シーケンスに付けられる (1 地点 1 日で数 KB の見込み)。観測所が近くに無いシーケンス (mini では 2 / 2) にも値が付くのが、観測所の照合に対する一番の利点。ただし値はモデルのもので、局所の突風は表さない。強風の群・弱風の群に分ける材料として使い、正解とはしない (`docs/zod_weather_poc.md` §4 と同じ)。
