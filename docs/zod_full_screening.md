## 1. データの準備と時刻の補正

### 1.1 重複の除き方

- 同じ走行のシーケンスの OXTS を、時刻で重複を除いてつないだ
- 重なった時刻の値が完全に同じこと (40 組で差 0) と、同じ走行の車両データのファイルが同じこと (30 走行で md5 一致) を確かめた
- これで走行ごとに 1 本の時系列になる。**重なった OXTS の区間を別の標本として数えることはない**

### 1.2 時計のずれ (車両データ − OXTS)

**方法**

- 走行ごとの OXTS の全区間 (10 m/s 超、20 s 以上の区間) をまとめて、0.1〜2 Hz の相互相関の和をとり、最大の所を放物線で細かく求めた
- 不確かさは、区間を 1 つずつ除いた jackknife の標準誤差

**3 つの測り方**

| 測り方 | 何が分かるか |
|---|---|
| 横加速度 (車両 IMU vs OXTS) | 同じ物理量どうしなので、応答の遅れを含まない。**補正にはこれを使った** |
| ロール角速度 (車両 IMU vs OXTS) | 独立の確かめ。ロール角速度が 0 の 8 走行では使えない |
| 舵角 → 横加速度 (車両 IMU 側と OXTS 側) | 車両データの中だけの遅れ (時計のずれを含まない) と、OXTS 側の遅れ (含む) の比較 |

**結果** (中央値)

| | ほかの 167 走行 | sierra 2022-02 の 10 走行 |
|---|---|---|
| 時計のずれ: 横加速度 | −0.023 s | **−0.133 s** |
| 時計のずれ: ロール角速度 | +0.018 s | −0.082 s |
| ロール − 横加速度 | +0.041 s | +0.051 s |
| 舵角 → OXTS のヨー (補正前) | 0.050 s | **0.153 s** |
| 同 (時計のずれで補正後) | 0.025 s | **0.026 s** |
| 舵角 → 車両 IMU の横加速度 (車両データの中だけ) | 0.060 s | 0.084 s |

**判断**

- sierra の 2 月の走行の約 0.11 s の違いは**時刻同期の誤差**で、操舵の応答の遅れではない。根拠は 3 つある
  - 時計のずれで補正すると、舵角 → ヨーの遅れがほかの走行と同じ 0.026 s になる
  - 車両データの中だけで測った遅れは、ほとんど変わらない (差 0.02 s)
  - 独立した 2 つの信号 (横加速度とロール角速度) が、同じだけ (約 0.1 s) ずれている
- 舵角と横加速度は車両データの別のグループ (`ego_vehicle_controls` と `ego_vehicle_data`) にある。上の結果から、2 つは同じ時計で記録されているとみられる (推定)
- Phase 1 の「sierra 2 月は 8 走行」は、この実行では 10 走行 (−0.1 s より大きくずれた走行の数え方の違い)

**不確かさ**

- jackknife の標準誤差は走行の中央値で 0.005〜0.01 s
- ただし、ロール角速度で測ると、横加速度より 0.04 s (走行間の標準偏差 0.02 s) 遅く出る。センサーごとのフィルタの違いとみられ、**同期の絶対値には約 0.04 s の不確かさがある**
- 一定の分は、モデルの舵角の遅れ d (学習側で 0〜0.02 s が選ばれた) に吸収される
- 全 177 走行で横加速度から推定できた (相関 0.6 超)。車両の中央値で代える走行は無かった
- 図: `plots/clock_sync.png`

### 1.3 欠損・異常の扱い

| もの | 扱い |
|---|---|
| 車両データの途切れ (0.1 s を超える間隔) | その前後 1 s を判定から除く。事象の ±3 s にあれば「センサー異常の疑い」 |
| ロール角速度が 0 の 8 走行 | 時計のずれの確かめ (ロール) だけ使わない。判定には車両のロール角速度を使っていないので、ほかへの影響はない |
| OXTS の区間の端 2 s | フィルタの端なので除く |
| **OXTS の β が明らかにおかしい区間** | 区間の \|β\| の中央値が 3 deg を超える所 (例: uniform_20220404T114856 の一部の区間で 14〜19 deg)。速度の標準偏差から求めた β の不確かさ (0.04〜0.06 deg) では見つけられなかった。OXTS の姿勢の推定が不安定な区間とみられ、その区間の事象は「センサー異常の疑い」に回した |
| ロールの重力成分 | 直進・定速での (−accelY − v·r) と g·sin(roll) の関係の傾きが 1.00 (相関 0.95、12 万点)。OXTS の roll で重力を除いた |

## 2. 車両運動モデル

- **式**: r_pred = v·(δsw(t − d) − c) / (a + b·v²)。1 次遅れ τ も 0〜0.3 s で試したが、どの車両でも τ = 0 が選ばれた (残差は減らなかった)
- **当てはめ**: 学習側の走行の OXTS 区間 (10 m/s 超、方向指示器の前後 3 s を除く、20 Hz)。走行ごとのゼロ点 c_d を固定効果として a, b を求めた
- **車両の基準のゼロ点**: c_car = 学習側の走行の c_d の中央値
- **走行ごとの補正量 Δc**: 評価する走行の車両データの走行全体を 10 s ずつに区切り、次の区間だけで「δ の平均 − a·r/v − b·v·r」の中央値をとった
  - 70 km/h 以上
  - 衛星測位の方位から求めた |r| が 1 deg/s 未満
  - 方向指示器なし
  - **OXTS の区間から ±30 s 以上離れた所**
  - r は衛星の方位の変化率で、OXTS と照合して傾き 0.89・相関 0.96。区間 (10 s) が 30 以上ある走行だけ補正した
- 補正は 177 走行のうち 127 走行に当てた。残り 50 走行は高速の区間が足りず、c_car のまま (`offset_calib_by_drive.csv` の `applied`)
- 校正に使った時間の範囲は `calib_t0`・`calib_t1`・`calib_minutes` に記録した

### 2.3 補正が横風の当て舵を消してしまうか

- Δc は走行全体の中央値なので、**数分以内の当て舵 (突風・局所的な風) は消さない。** 校正には OXTS の区間の ±30 s を使っていない
- **走行中ずっと同じ向きから風を受け、進行方向もほぼ一定の場合は、当て舵の分が Δc に入って消える**
- 確かめとして、走行ごとの 10 s の区間のずれを、進行方向 H の c0 + A·sin H + B·cos H で当てはめた
  - 一定の向きの風なら、当て舵は進行方向とともに符号が変わり、振幅 A に出る
  - 振幅の中央値は 0.35 deg。並べ替え検定で p < 0.05 の走行は 127 のうち 42 だった
  - ただし隣り合う区間は独立でないので、p は小さく出すぎる
  - 有意な走行の振幅は中央値 0.75 deg で、100 km/h のヨーで約 0.3 deg/s にあたる
  - 振幅には、道路ごとの横断勾配の違いも入る。**風だけによるものとは言えない**
- 補正前と補正後の残差は両方保存した (`residuals/*.npz` の `dr_unc`, `dr_cor`、`candidates.csv` の `dr_unc_at_peak`)
- 持続型の事象 (80 km/h) は、補正前 15 件・補正後 12 件で、両方に出たものが 9〜11 件。補正で消えたのは 4 件、補正で新しく出たのは 3 件

### 2.4 横力・ヨーモーメントの外乱をどこまで見分けられるか (mini の結果から)

- **横加速度の残差だけでは弱い**: 車両データだけの横加速度の残差は、OXTS のヨー残差との一致が弱い (相関 0.04〜0.44)。ロールの重力成分と β の変化が主な原因 (`docs/zod_drive_validation.md` §1.5)。今回はヨー残差を主にし、横加速度は OXTS と車両 IMU の 2 つで確かめに使った
- **検出の限界は空力の作用点 x_cp による** (`docs/zod_weather_poc.md` §5)。作用点が中立操舵点の近くにあると、横力だけでヨーが出ず、20 m/s の突風でもヨー残差に表れない。x_cp ≥ 0.3〜0.7 m なら、90 km/h 以上で 3〜5 m/s の突風が見える
- 持続的な横力 (横風) と路面の横断勾配は、どちらも当て舵と負の横加速度残差を作る。ロール角で重力を除いた残差では区別できない。区別には次のどれかが要る
  - 路面の勾配 (地図・測量)
  - 同じ日の同じ道路の往復での符号の反転
  - 気象の照合

## 3. 交差検証

- **分け方**: 車両ごとに走行を 5 分割した (乱数の種は設定にある)。分割ごとに、学習側の走行で次を決め、評価側の走行に当てた
  - モデル: a, b, d, τ, c_car
  - 閾値 (下の 3 種)
- **走行ごとの校正と学習の分離**: 時計のずれと Δc は、走行ごとの校正として分けた
  - どちらも、その走行の信号から決めるが、モデルの学習 (a, b, d) と閾値には使っていない
  - Δc は OXTS の区間を使わない
- **閾値**: 学習側の走行の、80 km/h (または 70 km/h) 以上・直進の |値| の分位点
  - 突発型 (Δr − 10 s 平均): 99.9%
  - 持続型 (5 s 平均): 99.5%
  - 操舵が静かなときの突発型: 99.9%。始まりの前 1 s の |dδ/dt| の最大が 3 deg/s 未満の区間だけで決め、検出も同じ条件で
- **学習側の残差は当てはめに使ったデータの残差** (a, b は学習側で決めた) なので、評価側より少し小さく、閾値はやや低めに出ている

## 4. 一次スクリーニングと原因の仮説

### 4.1 判定の対象の区間

次のすべてを満たす区間を対象にした。

- 速さ ≥ 80 km/h (感度分析では 70)
- 道路の曲がり (|r| の 10 s 平均) が 1 deg/s 未満
- 方向指示器の前後 3 s を除く
- 車両データが有効
- OXTS の区間の端 2 s を除く

### 4.2 事象ごとの特徴量 (`candidates.csv`)

| 種類 | 列 |
|---|---|
| ヨー | 残差のピークと閾値比、始まりの時刻、持続時間、補正前・補正後の値。ピークまでの変化のうち実測の r (`dyaw_meas_deg_s`) と予測 r_pred (`dyaw_pred_deg_s`) の分と、その割合 |
| 横加速度 | 残差 (OXTS と車両 IMU)、2 つの一致 (相関) |
| β | 変化と品質 (不確かさ 0.1 deg 以下で、区間の \|β\| が正常) |
| 操舵 | 舵角が動いた時刻 (始まりとの差)、舵角の変化とその向き (逆向きの修正か)、始まりの前の舵角速度、トルクの変化と動いた時刻 |
| 走行条件 | 速さ、曲がり、方向指示器、車両データの途切れ、ヨーの角加速度 |
| 危険度に関わる量 (C) | 始まりの前の位置に当てた直線からの 4 s 後の横のずれ (`path_dev_4s_m`)、説明されないヨーの積分による方位・横のずれ (3 s) |

### 4.3 仮説の割り当て (上から順に最初に当たるもの)

| 仮説 | 条件 |
|---|---|
| 車線変更など (方向指示器) | 始まりの 10 s 前〜5 s 後に方向指示器 |
| センサー異常の疑い | ±3 s に車両データの途切れ、\|dr/dt\| > 30 deg/s²、2 つの横加速度の相関 < 0.5、または OXTS の β の異常の区間 |
| 持続的なずれ | 持続型 (5 s 平均) で検出 |
| 道路の曲がりの変化 | 前後で 10 s 平均の \|r\| が 0.5 deg/s 以上変わる |
| ヨーの変化が先 (外乱の候補) | 変化の 65% 以上が実測の r から来て、かつ、始まりの前に操舵が静か、または舵角が動いたのが始まりの 0.15 s 後より遅い |
| 操舵が先 (運転者の操作・モデルの誤差) | 上のどれでもない |

**ヨー残差だけで横風とは判定していない。** 仮説ごとの不確かさの説明は `candidates.csv` の `uncertainty` にある。

## 6. 異常の原因の仮説と不確かさ (まとめ)

| 仮説 | 主な誤検出・混同の原因 | 確かめる方法 |
|---|---|---|
| 車線変更など | 方向指示器の無い車線変更は「操舵が先」に入る | 前方映像 |
| 操舵が先 | 運転者の大きな操舵 (3〜16 deg) で、定常のモデルが外れる (τ を入れても改善しなかった) | 操舵の動きの大きさで除く条件の検討、映像 |
| 道路の曲がりの変化 | カーブの入口・出口 | 地図、映像 |
| センサー異常の疑い | OXTS の姿勢の推定の不安定 (β の異常)、車両データの途切れ | 区間ごとの品質の列の追加 |
| 持続的なずれ | 路面の横断勾配、ゼロ点の補正の誤差 (Δc の信頼区間 ±0.1 deg、ヨーで ±0.04 deg/s)、横風 | 気象の照合 (Phase 3)、路面の勾配、同じ日の往復 |
| ヨーの変化が先 | 路面からの入力 (トルクが同時に動く)、追い越しの車の風圧、横風の突風 | 気象の照合、映像 (路面・周りの車) |

## 8. 残っている課題

1. **判定の対象が短い**: 80 km/h 以上・直進は 126 分 (車両あたり 12〜47 分)。閾値 (99.5〜99.9% 点) も閾値超過率も、少ない時間から決めている
2. **閾値は操作中の残差の影響を受ける**: 静かなときの経路を足したが、運転者の操作中に起きた外乱は「操舵が先」と区別できない
3. **持続的なずれの原因**: 横風と路面の横断勾配を車両の信号だけでは分けられない。同じ日の往復や気象の照合が要る
4. **β の品質**: 速度の標準偏差による不確かさでは、OXTS の姿勢の不安定を見つけられない。区間の |β| による確かめを足したが、どの値から異常とするか (3 deg) は仮の値
5. **時刻の同期**: 絶対値に約 0.04 s の不確かさ (ロールと横加速度の差) がある。sierra 2 月のずれは補正した
6. **再通過による確かめができない**: OXTS が 50 s ずつしかなく、同じ地点の別の通過がほとんど無い。走行全体の車両データ (ヨーレートなし) で、道路の要因を調べる方法の検討が要る
7. **危険度 (C)**: 横のずれ (4 s) は、始まりの前の直線に対する位置のずれで、車線の中の位置ではない。車線の逸脱は判断していない
