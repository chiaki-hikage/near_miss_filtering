# ZOD mini: 走行全体の車両データの調査と、外乱推定モデルの確かめ

2026-11-12。ZOD Sequences mini (2 シーケンス、`raw_data/zod/`) だけを使い、ネットワークは使っていない。前段の調査は `docs/zod_signals.md`、full の取得と解析の計画は `docs/zod_full_plan.md`。

- コード: `scripts/zod/drive_validation.py` (設定 `configs/zod/drive_validation.yaml`。前処理は `configs/zod/signal_survey.yaml` を共用)
- 出力: `out/zod/drive_validation/mini/` (CSV 14 個と `plots/`)
- 実行: `uv run --offline --extra viz --with "zod==0.8.0" --with "dataclass-wizard==0.39.1" python scripts/zod/drive_validation.py --root raw_data/zod --version mini`

**2 台・2 走行だけの結果で、一般化はできない。横風の正解ラベルは無く、ここでの残差の大きさから横風とは判断しない。**

## 0. まとめ

| 問い | 答え |
|---|---|
| 長時間の車両データで GNSS の位置と日時が取れるか | **取れる。** 車両データの衛星測位 (`satellite`) に、走行の最初から最後まで UTC (年月日時分秒と、ns の記録時刻) と緯度経度がある。位置の更新は約 1.04 s ごと、1 Hz の欠けは 0.3〜1.5%。位置の誤差は、RTK の OXTS と比べて 3〜4 m (中央値 3.3 m、000000) |
| 操舵・トルク・横加速度・車速の連続記録 | 55 分・98 分の走行で、どの信号も 99.9% の時間がある。途切れは 3〜6 回、最長 1.3 s |
| 50 s の OXTS との対応 | OXTS の区間は、000000 で走行の 3.9 分目、000002 で 89.7 分目。同じ時計 (§1.4) |
| 車両データだけで長時間の横方向の異常を見られるか | **粗いふるい分けまで。** 車両データの横加速度の残差 (0.2〜2 Hz) は、OXTS のヨー残差と相関が 0.04〜0.44 しかなく、2〜3.5 倍大きい。ロールによる重力の成分と横滑りの変化が主で、ロールの補正で 3 割ほど減る。カーブの多い道では、閾値を超える所の多くが普通のカーブ |
| 時間で分けた評価 | OXTS の 50 s を 5 つに分けた交差検証と、前半 → 後半の評価で、ヨー残差の標準偏差は 0.12〜0.23 deg/s。走行全体の横加速度のモデルも、前半 → 後半で残差 (0.2〜2 Hz) の大きさはほぼ同じ |
| ゼロ点のずれと遅れ | 中立のずれは車両ごとに 3 つの方法で 1.5〜2.1 deg (quebec)、3.7〜5.3 deg (romeo)。舵角 → ヨーレートの遅れ 0.04〜0.06 s。予測に 0.05 s の遅れを入れると、ヨー残差は 15〜37% 小さくなる |
| 横滑り角 | OXTS の `slipAngle` = atan2(横速度, 前後速度) [deg]。GNSS の 2 本のアンテナと IMU の組み合わせで測った値。精度は測位の状態に強く依る: 000000 (RTK) は速度の誤差から 0.05 deg、000002 は 1.2 deg で、**000002 では横滑り角そのものより誤差が大きい** |
| OXTS と車両 IMU は独立か | 別のセンサで、同じ量 (横加速度・ロール角速度) を測っている。0.1〜2 Hz ではよく一致 (コヒーレンス 0.89〜1.0)、2 Hz を超えると一致が落ちる。センサの故障・雑音の確かめには使えるが、物理的に別の観測ではない。**ヨーレートは OXTS にしか無い** |

### 1.5 車両データだけで長時間の横方向の異常を見られるか

| 確かめたこと | 000000 | 000002 | 出力 |
|---|---|---|---|
| 車両データの横加速度の残差 (0.2〜2 Hz) と、OXTS のヨー残差 (v·Δr、同じ帯域) の相関 | **0.04** | **0.44** | `vehicle_only.csv` |
| 同じ式で横加速度だけ OXTS に替えたものとの相関 | 0.98 | 0.89 | 同 |
| 大きさ (標準偏差): 車両の横加速度の残差 / ヨー残差 | 0.117 / 0.035 m/s² | 0.042 / 0.020 m/s² | 同 |
| 衛星の方位 (約 1 Hz) から求めたヨーレートと OXTS (0.3 Hz の低域) | 相関 0.94、差の RMS 0.85 deg/s | 相関 0.53、0.34 deg/s | 同 |

0.2〜2 Hz の横加速度の内訳 (`ay_terms.csv`、標準偏差):

| 項 | 000000 | 000002 |
|---|---|---|
| ヨー残差 v·Δr (OXTS) | 0.035 | 0.020 |
| 車両の ay − v·r | 0.124 | 0.040 |
| 同 − g·φ (φ は車両のロール角速度を積分したロール角) | 0.082 | 0.032 |
| 参考: v·dβ/dt (OXTS の横滑り角の変化) | 0.099 | 0.055 |

- 横加速度は ay = v·(r + dβ/dt) + g·φ (+ 路面の傾き) なので、ヨーの外乱以外に、**車体のロールと横滑りの変化**が入る。0.2〜2 Hz ではそれらがヨー残差より大きい
- 車両のロール角速度の積分で重力の成分を除くと 3 割ほど減る (000000 で 0.124 → 0.082)。残りは横滑りの変化とみられる。横風も横滑りを起こすので、この残りを雑音として捨てることはできない
- 走行全体での閾値の超過 (`detections.csv`、高速・直進の残差の 99.9% 点を車両ごとの閾値): 000000 は 57 か所 (閾値 0.25 m/s²)、000002 は 31 か所 (0.64 m/s²)。**000000 の大半は「曲がり」の区間**で、普通のカーブを拾っている
- 衛星の方位からのヨーレートは、ゆっくりした曲がり (カーブと路面の傾きを分ける) には使えそうだが、突風の帯域 (0.2〜2 Hz) には粗すぎる

**判断**: 車両データだけでは、横加速度の異常の「ふるい分け」はできるが、ヨーの外乱の推定には足りない。外乱の評価は OXTS の 50 s で行い、走行全体の車両データは (1) 候補の時間帯の絞り込み、(2) 運転者の当て舵 (トルク) の確認、(3) 位置と時刻 (気象の照合) に使うのがよい。ロールの補正と、衛星の方位によるゆっくりした曲がりの補正を入れれば、ふるい分けの精度は上がる見込み (未実施)。

## 2. 外乱推定モデルの確かめ

### 2.1 時間で分けた評価 (`window_cv.csv`, `drive_split.csv`)

OXTS の 50 s のヨーのモデル (δsw = a·(r/v) + b·(v·r) + c):

| 評価のしかた | 000000 | 000002 |
|---|---|---|
| 5 ブロックの交差検証 (評価の 10 s の前後 1 s は当てはめに使わない) | 0.230 deg/s | 0.135 deg/s |
| 前半で当てはめ → 後半で評価 | 0.220 deg/s | 0.116 deg/s |
| 参考: 前回の 2 分割 (`docs/zod_signals.md`) | 0.241 | 0.149 |

走行全体の横加速度のモデル (高速・直進の区間の 0.2〜2 Hz の残差の標準偏差):

| | 000000 | 000002 |
|---|---|---|
| 前半 → 後半 | 0.057 m/s² | 0.073 |
| 後半 → 前半 | 0.063 | 0.081 |
| 全体 → 全体 (参考) | 0.059 | 0.088 |
| ゆっくりした成分 (0.2 Hz 未満) の残差 | 0.10〜0.15 | 0.18〜0.33 |

- 0.2〜2 Hz の残差は、当てはめの期間を変えてもほとんど変わらない。ゆっくりした成分は期間で大きく変わり (路面の傾き・見かけの a, b)、使えない
- 当てはめた a, b は期間で大きく変わる (000000: a = 31.7 ↔ 51.0 m)。速度と横加速度の幅が狭いと a と b が分かれない。予測 (a + b·v²) は安定している

### 2.5 横滑り角の定義と測り方 (`slip.csv`)

| 項目 | 内容 |
|---|---|
| 定義 | OXTS の `slipAngle` [deg] = atan2(`velLateral`, `velForward`) (データで一致を確認、`docs/zod_signals.md` §2.2)。右が正 (y 右) |
| 測る点 | OXTS の速度の出力点。r/v との関係 (β ≈ 傾き·r/v + ずれ) の傾きは 0.65 m (000000)、0.45 m (000002)。後車軸の中心からこの距離だけ前の点で測った横滑り角と考えると説明がつく (タイヤの横すべりが小さい場合。推定)。出力点の位置は文書から確定できなかった |
| 測り方 | OXTS RT3000 は、GNSS (2 本のアンテナによる方位 `GNSSAntenna/headingAntennas` と速度) と IMU を組み合わせて、車体の向きと進む向きを別々に求める。横滑り角はその差で、車両のモデルからの推定ではない (NVIDIA の Ego Motion とは違う) |
| 不確かさ | 速度の標準偏差 / 速さから: **000000 は 0.05 deg、000002 は 1.24 deg** (中央値)。方位の標準偏差は 0.13〜0.16 deg |
| 直進中の散らばり (\|r\| < 0.5 deg/s) | 000000: 0.14 deg (9.6 s)、000002: 0.05 deg (39.9 s) |
| 範囲 | 000000: −0.72〜0.12 deg、000002: −0.24〜0.16 deg |

- 000002 は、横滑り角の値 (±0.2 deg) より不確かさ (1.2 deg) のほうが大きい。**横滑り角を使うのは、OXTS の測位が RTK のとき (速度の標準偏差が小さいとき) に限る**必要がある。full では、シーケンスごとに `stdDevVel*` で選ぶ
- 000002 の直進中の散らばりが小さいのは、OXTS 内部の平滑化 (カルマンフィルタ) によるとみられる (推定)。小さい散らばりを精度とみなさない
- 車両データの `lat_vel` は OXTS と合わない (`docs/zod_signals.md`)。横滑り角には使わない

### 2.6 車両ごとの正常の残差の分布

2 台・各 1 走行しかなく、「正常の分布」と呼ぶには足りない。今ある値:

| | 000000 (quebec) | 000002 (romeo) |
|---|---|---|
| ヨー残差 (OXTS の 50 s、5 ブロック) の標準偏差 / \|p99\| | 0.23 / 0.61 deg/s | 0.135 / 0.45 deg/s |
| 横加速度の残差 (高速・直進、0.2〜2 Hz) の \|p99\| | 0.17〜0.23 m/s² (速さによる) | 0.14〜0.54 m/s² |
| 操舵トルクの標準偏差 (高速・直進) | 0.73〜0.75 N·m | 0.58〜0.84 N·m |

full では、車両 (`collection_car`) × 速さ × 区間の種類ごとに、多くのシーケンスで分布を作り、外乱の候補はその分布に対する外れ方で表す (`docs/zod_full_plan.md` §4)。

### 2.7 OXTS と車両 IMU を独立した観測として使える範囲 (`independence.csv`)

| 量 | 0.1–0.5 Hz | 0.5–2 Hz | 2–5 Hz | 5–10 Hz | 5–20 Hz の強さ (車両 / OXTS) |
|---|---|---|---|---|---|
| 横加速度 (000000 / 000002) | 0.996 / 0.992 | 0.971 / 0.891 | 0.66 / 0.60 | 0.49 / 0.36 | 0.76 / 0.81 |
| ロール角速度 | 1.000 / 0.983 | 0.999 / 0.991 | 0.95 / 0.98 | 0.77 / 0.83 | 0.66 / 0.72 |
| 縦加速度 | 0.92 / 0.98 | 0.25 / 0.40 | 0.11 / 0.20 | 0.15 / 0.11 | 0.75 / 0.55 |

(値はコヒーレンスの平均)

| 使い方 | 判断 |
|---|---|
| 横加速度・ロール角速度の、センサの故障・飛び・取付けの雑音の確かめ (2 Hz 以下) | **使える**。2 つのセンサが同時に示す変化は、センサの作り物ではない |
| 2 Hz を超える振動 | 一致が落ちる。取付け位置・平滑化の違いとみられる (車両の 5–20 Hz の強さは OXTS の 0.55〜0.81 倍) |
| 外乱の「独立した証拠」 | **使えない**。2 つは同じ物理量を測っているので、片方で見えた横加速度の変化をもう片方で確かめても、原因 (風か、路面か、操舵か) は分からない |
| ヨーレート | **OXTS にしか無い**。舵角 (原因) と OXTS のヨーレート (結果) は別の系統なので、ヨー残差は独立な 2 つの観測の差になる |
| 縦方向 | 0.5 Hz を超えると一致しない (車両の縦加速度は車輪の速さからの値かもしれない。未確認) |
