# reports/ca/ — AI 駆動開発の活用事例・ノウハウ・課題

C&A (FY26 2H) の目標 2「生成 AI 活用による開発・業務生産性向上への貢献」のための記録。このプロジェクトで Claude Code や Codex を使った作業から、事例・ノウハウ・課題を集める。

- `cases.md`: 事例の記録 (1 件 1 節)。末尾に、事例から抜き出したノウハウと課題の一覧

## 書き方

- 事例は**起きたこと**を書く。効果を数字で書くのは、測ったものだけ (作業時間の短縮などを見積もりで書かない)
- AI の誤りや、人が止めた場面も事例にする。課題の材料になる
- 根拠を付ける: コミット、文書、`experiments/index.csv` の行、セッションの記録の日時
- AI が出した判定と人の判定を区別する (例: 目視の記録に AI の暫定判定が混ざっている場合は、そう書く)
- 部内に共有するときは、`cases.md` の該当する節とノウハウ・課題の一覧から作る

## 1 件の書き方

```
## YYYY-MM-DD 見出し

- 作業: 何を AI にさせたか
- 使ったもの: Claude Code / Codex など
- 結果: 何ができたか、何が起きたか
- 効果: (測ったものだけ)
- 課題・注意: うまくいかなかったこと、人が直したこと
- 根拠: コミット・文書・ファイル
```
